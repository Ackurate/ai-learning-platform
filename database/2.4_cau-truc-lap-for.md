## Cấu trúc lặp for {#cau-truc-lap-for}

Cấu trúc `for` dùng để lặp lại nhiều lần một đoạn lệnh với biến đếm khởi tạo, điều kiện lặp và bước cập nhật rõ ràng.

**Cú pháp:**
```cpp
for (dãy_biểu_thức_1; điều_kiện_lặp; dãy_biểu_thức_2)
    khối_lệnh_lặp;
```
- Các biểu thức trong `dãy_biểu_thức_1`, `dãy_biểu_thức_2` phân cách nhau bởi dấu phẩy `,`.
- Các thành phần trong `for` có thể để trống nhưng **vẫn phải giữ lại 2 dấu chấm phẩy `;`** để ngăn cách các thành phần với nhau (ví dụ `for ( ; i >= 1; i = i - 2)`).

**Cách thực hiện:**
1. Thực hiện `dãy_biểu_thức_1` **1 lần duy nhất** ngay từ đầu quá trình lặp.
2. Kiểm tra `điều_kiện_lặp`:
   - Nếu **đúng**: thực hiện `khối_lệnh_lặp` -> thực hiện `dãy_biểu_thức_2` -> quay lại kiểm tra `điều_kiện_lặp`.
   - Nếu **sai**: dừng vòng lặp `for`.

**Lệnh `for` lồng nhau:**
Trong khối lệnh lặp của `for` có thể chứa một lệnh `for` khác để duyệt nhiều biến (như bài toán cổ vừa gà vừa chó 36 con, 100 chân hoặc bài toán đổi 100$ ra các tờ 10$, 20$, 50$).

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int g = 0; g <= 50; g++)
        for (int c = 0; c <= 25; c++)
            if (g + c == 36 && 2 * g + 4 * c == 100)
                cout << "Ga = " << g << " Cho = " << c << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Trong cấu trúc `for (dãy_biểu_thức_1; điều_kiện_lặp; dãy_biểu_thức_2)`, thành phần `dãy_biểu_thức_1` được thực hiện bao nhiêu lần?
- A. Thực hiện ở mỗi vòng lặp trước khi kiểm tra điều kiện.
- B. Thực hiện ở mỗi vòng lặp sau khi chạy xong khối lệnh lặp.
- C. Thực hiện duy nhất 1 lần ngay từ đầu quá trình lặp.
- D. Không thực hiện lần nào nếu điều kiện lặp sai ngay từ đầu.

**Đáp án đúng:** C

**Giải thích:** Khi gặp câu lệnh `for`, `dãy_biểu_thức_1` được thực hiện 1 lần duy nhất ngay từ đầu quá trình lặp, sau đó mới kiểm tra `điều_kiện_lặp`.

**Câu 2:** Đoạn code sau in ra kết quả gì?

```cpp
int s = 0;
for (int i = 1; i <= 5; i += 2)
    s += i;
cout << s;
```

- A. `15`
- B. `9`
- C. `6`
- D. `10`

**Đáp án đúng:** B

**Giải thích:** Biến `i` nhận lần lượt các giá trị lẻ `1, 3, 5` (do bước nhảy `i += 2`). Tổng `s = 1 + 3 + 5 = 9`.
