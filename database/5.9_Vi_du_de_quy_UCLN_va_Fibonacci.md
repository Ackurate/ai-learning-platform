## Mục tiêu bài học {#muc-tieu-bai-hoc}

Sau khi học xong bài này, người học có thể:

- Hiểu cách sử dụng đệ quy để tìm ước chung lớn nhất (UCLN) của hai số nguyên dương.
- Hiểu cách sử dụng đệ quy để tính số hạng thứ \(n\) của dãy Fibonacci.
- Nhận biết trường hợp cơ sở và trường hợp đệ quy trong chương trình.

## Ví dụ 1: Tìm UCLN của hai số nguyên dương {#tim-ucln}

UCLN là viết tắt của **ước chung lớn nhất**, tức là số nguyên dương lớn nhất chia hết cả hai số đã cho.

Có thể sử dụng đệ quy để tìm UCLN theo các quy tắc:

- Nếu \(a=b\), UCLN bằng \(a\).
- Nếu \(a<b\), ta có \(UCLN(a,b)=UCLN(a,b-a)\).
- Nếu \(a>b\), ta có \(UCLN(a,b)=UCLN(a-b,b)\).

### Chương trình {#chuong-trinh-ucln}

```cpp
#include <iostream>
using namespace std;

int UCLN(int a, int b)
{
    if (a == b)
        return a;
    else if (a < b)
        return UCLN(a, b - a);
    else
        return UCLN(a - b, b);
}

int main()
{
    int a, b;

    cout << "Nhap 2 so nguyen duong a va b = ";
    cin >> a >> b;

    if (a <= 0 || b <= 0)
    {
        cout << "Vui long nhap hai so nguyen duong." << endl;
        return 1;
    }

    cout << "UCLN(" << a << ", " << b << ") = ";
    cout << UCLN(a, b) << endl;

    return 0;
}
```

### Giải thích {#giai-thich-ucln}

Hàm `UCLN(a, b)` so sánh hai số:

- Nếu hai số bằng nhau, hàm trả về số đó. Đây là **trường hợp cơ sở**.
- Nếu `a < b`, hàm gọi lại chính nó với hai đối số `a` và `b - a`.
- Nếu `a > b`, hàm gọi lại chính nó với hai đối số `a - b` và `b`.

Quá trình tiếp tục cho đến khi hai số bằng nhau. Khi đó, hàm trả về kết quả UCLN.

Ví dụ, với `a = 12` và `b = 8`:

1. `UCLN(12, 8)` gọi `UCLN(4, 8)`.
2. `UCLN(4, 8)` gọi `UCLN(4, 4)`.
3. `UCLN(4, 4)` trả về `4`.

Vậy UCLN của 12 và 8 là 4.

### Câu hỏi kiểm tra {#cau-hoi-ucln}

Với lời gọi `UCLN(12, 8)`, kết quả cuối cùng mà hàm trả về là bao nhiêu?

- A. 2
- B. 4
- C. 8
- D. 12

**Đáp án: B.** Vì quá trình đệ quy đưa hai số về `UCLN(4, 4)`, và hàm trả về 4 khi hai số bằng nhau.

## Ví dụ 2: Tính số hạng thứ \(n\) của dãy Fibonacci {#day-fibonacci}

Dãy Fibonacci được định nghĩa như sau:

\[
f(1)=f(2)=1
\]

\[
f(n)=f(n-1)+f(n-2),\quad n>2
\]

Theo công thức trên, mỗi số hạng từ số hạng thứ ba trở đi bằng tổng của hai số hạng đứng ngay trước nó.

Một số số hạng đầu tiên của dãy Fibonacci là:

\[
1,\ 1,\ 2,\ 3,\ 5,\ 8,\ 13,\ 21,\ldots
\]

### Chương trình đệ quy {#chuong-trinh-fibonacci}

```cpp
#include <iostream>
using namespace std;

long Fibo(int n)
{
    if (n == 1 || n == 2)
        return 1;
    else
        return Fibo(n - 1) + Fibo(n - 2);
}

int main()
{
    int n;

    cout << "Nhap n = ";
    cin >> n;

    if (n < 1)
    {
        cout << "Vui long nhap n >= 1." << endl;
        return 1;
    }

    cout << "So hang thu " << n
         << " trong day Fibonacci la ";
    cout << Fibo(n) << endl;

    return 0;
}
```

### Giải thích {#giai-thich-fibonacci}

Hàm `Fibo(n)` tính số hạng thứ `n` của dãy Fibonacci:

- Nếu `n == 1` hoặc `n == 2`, hàm trả về `1`. Đây là **hai trường hợp cơ sở**.
- Nếu `n > 2`, hàm tính tổng của `Fibo(n - 1)` và `Fibo(n - 2)`.
- Kết quả được trả về trực tiếp từ hàm.

Ví dụ, khi nhập `n = 6`:

\[
f(6)=f(5)+f(4)=5+3=8
\]

Vậy số hạng thứ sáu của dãy Fibonacci là 8.

**Lưu ý:** Cách viết đệ quy này dễ hiểu nhưng có thể tính toán lặp lại nhiều lần khi `n` lớn. Ngoài ra, kiểu `long` có giới hạn lưu trữ, nên kết quả có thể bị tràn khi số hạng quá lớn.

### Câu hỏi kiểm tra {#cau-hoi-fibonacci}

Trong hàm `Fibo(n)`, trường hợp nào được dùng làm trường hợp cơ sở?

- A. `n == 0`
- B. `n < 2`
- C. `n == 1 || n == 2`
- D. `n > 2`

**Đáp án: C.** Khi `n` bằng 1 hoặc 2, hàm trả về 1 mà không gọi đệ quy tiếp.

## Câu hỏi ôn tập {#cau-hoi-on-tap}

**Câu 1.** Khi tìm UCLN bằng hàm đệ quy đã cho, điều kiện nào khiến hàm dừng và trả về kết quả?

- A. Khi `a == 0`
- B. Khi `b == 0`
- C. Khi `a == b`
- D. Khi `a < b`

**Đáp án: C.** Khi `a == b`, hai số bằng nhau và giá trị đó chính là UCLN.

**Câu 2.** Theo định nghĩa dãy Fibonacci, giá trị của `Fibo(6)` là bao nhiêu?

- A. 5
- B. 6
- C. 8
- D. 13

**Đáp án: C.** Dãy bắt đầu bằng \(1, 1, 2, 3, 5, 8\), nên số hạng thứ sáu bằng 8.
