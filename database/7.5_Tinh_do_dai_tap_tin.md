## Mục tiêu bài học {#muc-tieu-bai-hoc}

Sau bài học, người học có thể:

- Mở tập tin ở chế độ nhị phân để đọc dữ liệu.
- Tính độ dài tập tin bằng cách đọc và đếm từng byte.
- Sử dụng `seekg()` và `tellg()` để xác định độ dài tập tin.
- Kiểm tra trạng thái tập tin trước khi thực hiện thao tác đọc.

## Yêu cầu bài toán {#yeu-cau-bai-toan}

Viết chương trình cho phép người dùng nhập tên tập tin. Nếu tập tin không tồn tại hoặc không mở được thì thông báo lỗi; ngược lại, chương trình in ra độ dài của tập tin tính bằng byte.

Bài học giới thiệu hai phương pháp:

- Đọc từng byte và đếm số byte đã đọc.
- Di chuyển vị trí đọc đến cuối tập tin rồi lấy vị trí hiện tại.

## Cách 1: Đọc từng byte để tính độ dài {#cach-1-doc-tung-byte}

### Chương trình

```cpp id="q8w3mt"
#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    char fname[20];
    char ch;
    long dodai = 0;

    cout << "Nhap ten file can mo: ";
    cin.getline(fname, 20);

    ifstream f(fname, ios::binary);

    if (!f)
    {
        cout << "Khong mo duoc file " << fname;
        return 1;
    }

    while (f.get(ch))
    {
        dodai++;
    }

    if (f.bad())
    {
        cout << "Co loi khi doc file";
        f.close();
        return 1;
    }

    f.close();

    cout << "Do dai cua file " << fname << " la: ";
    cout << dodai << " byte" << endl;

    return 0;
}
```

### Giải thích

- `ifstream f(fname, ios::binary)`: Mở tập tin ở chế độ nhị phân để đọc.
- `long dodai = 0`: Khởi tạo biến đếm độ dài tập tin.
- `f.get(ch)`: Đọc một ký tự từ tập tin. Khi mở ở chế độ nhị phân, mỗi lần đọc thành công sẽ lấy một byte.
- `dodai++`: Tăng biến đếm sau mỗi lần đọc thành công.
- `f.bad()`: Kiểm tra xem có lỗi đọc nghiêm trọng hay không.
- `f.close()`: Đóng tập tin sau khi đọc xong.

Khi kết thúc vòng lặp do đã đọc đến cuối tập tin, biến `dodai` chứa số byte đã đọc được, nếu không xảy ra lỗi đọc.

### Câu hỏi kiểm tra

**Trong phương pháp thứ nhất, biến `dodai` được sử dụng để làm gì?**

A. Lưu tên tập tin.

B. Đếm số byte đọc thành công từ tập tin.

C. Lưu vị trí bắt đầu của tập tin.

D. Kiểm tra tập tin có tồn tại hay không.

**Đáp án: B.** Mỗi lần `f.get(ch)` đọc thành công một byte, biến `dodai` được tăng thêm một đơn vị.

## Cách 2: Sử dụng `seekg()` và `tellg()` {#cach-2-seekg-va-tellg}

### Chương trình

```cpp id="k3j8vn"
#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    char fname[20];

    cout << "Nhap ten file can mo: ";
    cin.getline(fname, 20);

    ifstream f(fname, ios::binary);

    if (!f)
    {
        cout << "Khong mo duoc file " << fname;
        return 1;
    }

    f.seekg(0, ios::end);

    if (!f)
    {
        cout << "Khong xac dinh duoc vi tri cuoi file";
        f.close();
        return 1;
    }

    auto dodai = f.tellg();

    if (dodai == -1)
    {
        cout << "Khong xac dinh duoc do dai file";
        f.close();
        return 1;
    }

    cout << "Do dai cua file " << fname << " la: ";
    cout << dodai << " byte" << endl;

    f.close();

    return 0;
}
```

### Giải thích

- `f.seekg(0, ios::end)`: Di chuyển vị trí đọc đến cuối tập tin.
- `f.tellg()`: Trả về vị trí hiện tại của luồng đọc. Khi vị trí đọc ở cuối tập tin nhị phân, giá trị này thường cho biết độ dài tập tin tính bằng byte.
- `auto dodai`: Để trình biên dịch tự xác định kiểu dữ liệu phù hợp với giá trị trả về của `tellg()`.
- `dodai == -1`: Kiểm tra trường hợp không xác định được vị trí hiện tại.
- `f.close()`: Đóng tập tin sau khi sử dụng.

### Câu hỏi kiểm tra

**Khi sử dụng `f.seekg(0, ios::end)`, vị trí đọc được chuyển đến đâu?**

A. Đầu tập tin.

B. Giữa tập tin.

C. Cuối tập tin.

D. Vị trí trước byte đầu tiên.

**Đáp án: C.** `ios::end` xác định cuối tập tin làm mốc, còn độ lệch `0` đưa vị trí đọc đến đúng mốc đó.

## So sánh hai cách tính độ dài tập tin {#so-sanh-hai-cach}

| Tiêu chí | Cách 1: Đọc từng byte | Cách 2: Dùng `seekg()` và `tellg()` |
|---|---|---|
| Hàm sử dụng | `get()` | `seekg()`, `tellg()` |
| Nguyên tắc | Đọc từng byte và đếm | Đưa vị trí đọc đến cuối rồi lấy vị trí |
| Đặc điểm | Phải đọc lần lượt toàn bộ dữ liệu | Thường nhanh hơn vì không cần đọc từng byte |
| Kiểm tra lỗi | Cần phân biệt kết thúc tập tin với lỗi đọc | Cần kiểm tra việc di chuyển và lấy vị trí có thành công không |

Cả hai phương pháp đều có thể xác định độ dài tập tin tính bằng byte khi thao tác thành công. Phương pháp thứ hai thường gọn và hiệu quả hơn khi chỉ cần biết kích thước tập tin.

### Câu hỏi kiểm tra

**Nếu mục tiêu chỉ là xác định độ dài tập tin, phương pháp nào thường hiệu quả hơn?**

A. Đọc từng byte và đếm.

B. Dùng `seekg()` đến cuối tập tin rồi gọi `tellg()`.

C. Đọc tập tin nhiều lần bằng `getline()`.

D. Ghi lại toàn bộ tập tin sang một tập tin khác.

**Đáp án: B.** Phương pháp này xác định vị trí cuối tập tin mà không cần đọc lần lượt toàn bộ dữ liệu.

## Kết luận {#ket-luan}

Có thể tính độ dài tập tin nhị phân bằng cách đọc từng byte và đếm số byte, hoặc sử dụng `seekg()` và `tellg()` để xác định vị trí cuối tập tin. Khi thao tác, cần kiểm tra việc mở tập tin thành công và xử lý lỗi đọc nếu có.

A. Cả hai đều dùng để đóng tập tin.
