## Cấu trúc rẽ nhánh if và if...else

Thông thường chương trình thực hiện tuần tự từng lệnh từ đầu đến cuối. Cấu trúc `if` cho phép chương trình rẽ nhánh, thực hiện khối lệnh này hay khối lệnh khác phụ thuộc vào biểu thức điều kiện là đúng (khác `0`) hay sai (bằng `0`).

**Cú pháp:**
```cpp
if (điều_kiện)
    khối_lệnh_1;
else
    khối_lệnh_2;
```
(Phần `else khối_lệnh_2;` có thể có hoặc không).

**Đặc điểm và các lưu ý quan trọng:**
- Biểu thức `điều_kiện` sau `if` bắt buộc phải đặt trong cặp dấu ngoặc đơn `( )`.
- Nếu `khối_lệnh_1` hoặc `khối_lệnh_2` có nhiều hơn 1 câu lệnh thì bắt buộc phải bao trong cặp dấu ngoặc móc `{ }`.
- Các câu lệnh `if` có thể lồng nhau. Khi nhiều câu lệnh `if` (có `else` và không `else`) lồng nhau, quy tắc là **`else` sẽ đi với `if` gần nó nhất mà chưa được ghép cặp với `else` khác**.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Nhap vao mot nam bat ky : ";
    cin >> n;
    if (n % 4 == 0 && n % 100 != 0 || n % 400 == 0)
        cout << n << " la nam nhuan" << endl;
    else
        cout << n << " la nam khong nhuan" << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Quy tắc ghép cặp của từ khóa `else` trong các câu lệnh `if` lồng nhau là gì?
- A. `else` luôn đi với câu lệnh `if` đầu tiên ngoài cùng.
- B. `else` luôn đi với câu lệnh `if` gần nó nhất mà chưa được ghép cặp với `else` khác.
- C. `else` đi với câu lệnh `if` có điều kiện sai.
- D. `else` chỉ dùng được khi không có `if` lồng nhau.

**Đáp án đúng:** B

**Giải thích:** Trong C++, `else` luôn kết hợp với `if` gần nó nhất ở phía trước mà chưa được ghép cặp với `else` nào khác.

**Câu 2:** Đoạn chương trình sau in ra kết quả gì khi `n = -5`, `a = 10`, `b = 20`?

```cpp
int n = -5, a = 10, b = 20, c = 0;
if (n > 0)
    if (a > b)
        c = a;
    else
        c = b;
cout << c;
```

- A. `10`
- B. `20`
- C. `0`
- D. `-5`

**Đáp án đúng:** C

**Giải thích:** Nhánh `else` đi với `if (a > b)` bên trong khối của `if (n > 0)`. Vì `n = -5` làm điều kiện `n > 0` sai ngay từ đầu, toàn bộ khối lệnh bên trong không được thực hiện nên `c` giữ nguyên giá trị `0`.
