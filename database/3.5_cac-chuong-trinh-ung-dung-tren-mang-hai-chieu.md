## Các chương trình ứng dụng trên mảng hai chiều

Để duyệt toàn bộ ma trận `a` gồm `m` hàng, `n` cột, ta dùng 2 vòng lặp `for` lồng nhau (vòng ngoài theo hàng `i`, vòng trong theo cột `j`):

- **Đếm số phần tử là số chính phương trong ma trận nguyên:**
  Kiểm tra điều kiện `if (sqrt(a[i][j]) == (int)sqrt(a[i][j])) d++;`.
- **Sắp xếp các phần tử trên hàng `h` theo thứ tự giảm dần:**
  Giữ cố định chỉ số hàng `h`, dùng 2 vòng lặp cột `i` (từ `0` đến `n - 2`) và `j` (từ `i + 1` đến `n - 1`), nếu `a[h][i] < a[h][j]` thì hoán đổi `a[h][i]` và `a[h][j]`.
- **Các vị trí đặc biệt trên ma trận vuông cấp `n` (khi đánh chỉ số hàng `i`, cột `j` từ `1` đến `n`):**
  - **Đường chéo chính:** `i == j` (truy xuất trực tiếp `a[i][i]`).
  - **Đường chéo phụ:** `i + j == n + 1`.
  - **Đường biên của ma trận:** `i == 1 || i == n || j == 1 || j == n`.

```cpp
#include <iostream>
using namespace std;

int main() {
    float a[11][11] = {{0}, {0, 2.4, 3.1, 4.0}, {0, 5.2, 6.8, 1.5}, {0, 9.0, 7.3, 8.6}};
    int n = 3, d = 0;
    float s_phu = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++) {
            if (int(a[i][j]) % 2 == 0) d++;
            if (i + j == n + 1) s_phu += a[i][j];
        }
    cout << "So phan tu co phan nguyen chan = " << d << endl;
    cout << "Tong duong cheo phu = " << s_phu << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Với ma trận vuông `a` cấp `n` được đánh chỉ số hàng `i` và cột `j` từ `1` đến `n`, điều kiện để phần tử `a[i][j]` nằm trên đường chéo phụ là gì?
- A. `i == j`
- B. `i + j == n`
- C. `i + j == n + 1`
- D. `i == 1 || j == n`

**Đáp án đúng:** C

**Giải thích:** Khi đánh chỉ số hàng và cột từ `1` đến `n`, các phần tử trên đường chéo phụ thỏa mãn `i + j == n + 1` (còn trên đường chéo chính là `i == j`).

**Câu 2:** Trong ma trận số thực `float a[11][11];`, để kiểm tra xem phần tử `a[i][j]` có **phần nguyên là số chẵn** hay không, ta sử dụng điều kiện nào?
- A. `if (a[i][j] % 2 == 0)`
- B. `if (int(a[i][j]) % 2 == 0)`
- C. `if (sqrt(a[i][j]) % 2 == 0)`
- D. `if (a[i][j] / 2 == 0)`

**Đáp án đúng:** B

**Giải thích:** Toán tử lấy phần dư `%` chỉ áp dụng cho số nguyên, nên phải ép kiểu `int(a[i][j])` để lấy phần nguyên của số thực trước khi kiểm tra `% 2 == 0`.
