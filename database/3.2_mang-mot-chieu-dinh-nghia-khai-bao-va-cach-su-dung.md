## Mảng một chiều: Định nghĩa, khai báo và cách sử dụng

**1. Định nghĩa mảng một chiều (véc-tơ):**
Mảng một chiều là một dãy các phần tử có cùng kiểu được sắp kề nhau liên tục trong bộ nhớ và có cùng tên là tên mảng.
- Để phân biệt các phần tử, chúng được đánh số thứ tự (chỉ số / vị trí) bắt đầu từ **`0`** cho đến hết mảng.
- Nếu mảng có `N` phần tử thì chỉ số hợp lệ chạy từ **`0` đến `N - 1`**.

**2. Ba dạng khai báo mảng một chiều:**
```cpp
float a[3], b[3];                // Dạng 1: Khai báo không khởi tạo
int p[2] = {1, 3}, q[2] = {3, 5}; // Dạng 2: Khai báo có số phần tử và khởi tạo
int c[] = {2, 4, 6, 8};          // Dạng 3: Khởi tạo tự xác định số phần tử (4 phần tử)
```
*Lưu ý:* Ở dạng 3, nếu vắng mặt cả số phần tử lẫn dãy giá trị khởi tạo (như `int a[];`) là **sai cú pháp**.

**3. Cách sử dụng:**
- Truy xuất phần tử thứ `i` bằng cú pháp `<tên_mảng>[i]` (ví dụ `a[0]`, `a[1]`).
- **Không thể** áp dụng phép nhập, xuất, gán hay cộng trực tiếp lên toàn bộ tên mảng (như `cin >> a;` hoặc `c = a + b;` đều sai), mà phải thực hiện thông qua **từng phần tử** của mảng (thường kết hợp với vòng lặp `for`).

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[2] = {1, 3}, b[2] = {3, 5}, tong[2], tich[2];
    tong[0] = a[0] * b[1] + a[1] * b[0]; // Tử số tổng
    tong[1] = a[1] * b[1];               // Mẫu số tổng
    tich[0] = a[0] * b[0];               // Tử số tích
    tich[1] = a[1] * b[1];               // Mẫu số tích
    cout << "Phan so Tong = " << tong[0] << "/" << tong[1] << endl;
    cout << "Phan so Tich = " << tich[0] << "/" << tich[1] << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Cho khai báo mảng `char dong[80];`. Chỉ số của phần tử đầu tiên và phần tử cuối cùng trong mảng `dong` lần lượt là:
- A. `1` và `80`
- B. `0` và `80`
- C. `0` và `79`
- D. `1` và `79`

**Đáp án đúng:** C

**Giải thích:** Mảng có $N = 80$ phần tử được đánh số thứ tự từ `0` đến `N - 1 = 79`.

**Câu 2:** Cách khai báo mảng một chiều nào sau đây là SAI cú pháp trong C++?
- A. `int a[2] = {1, 3};`
- B. `int a[] = {1, 3, 5};`
- C. `int a[];`
- D. `long L[100];`

**Đáp án đúng:** C

**Giải thích:** Khai báo `int a[];` vắng mặt cả kích thước mảng lẫn dãy giá trị khởi tạo nên không hợp lệ trong C++.
