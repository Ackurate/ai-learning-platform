## Hằng số và biến {#hang-so-va-bien}

**1. Hằng số (Constant):**
Hằng số là một giá trị cố định không đổi trong suốt quá trình thực thi chương trình (ví dụ: hằng nguyên `3`, hằng ký tự `'A'`, hằng thực `5.0`, hằng chuỗi `"Viet Nam"`).

**Bảng các hằng ký tự đặc biệt thường dùng:**

| Hằng ký tự | Ý nghĩa |
| :--- | :--- |
| `'\n'` | Xuống hàng mới (tương đương `endl`) |
| `'\t'` | Ký tự Tab (khoảng 8 dấu cách) |
| `'\a'` | Ký tự chuông (phát tiếng 'bíp') |
| `'\r'` | Về đầu hàng / xuống hàng |
| `'\f'` | Kéo trang |
| `'\\'` | Dấu gạch chéo ngược `\` |
| `'\?'` | Dấu chấm hỏi `?` |
| `'\''` và `'\"'` | Dấu nháy đơn `'` và dấu nháy kép `"` |
| `'\kkk'` và `'\xkk'` | Ký tự có mã `kkk` hệ bát phân (hệ 8) và `kk` hệ thập lục phân (hệ 16) |

**Hai cách khai báo hằng có tên:**
```cpp
#define sosv 50
const int MAX = 100;
```

**2. Biến (Variable):**
Biến là vùng nhớ được đặt tên dùng để lưu trữ dữ liệu và **giá trị của biến có thể thay đổi** thông qua lệnh nhập hoặc lệnh gán.
- **Khai báo biến:** Có thể khai báo không khởi tạo (`int i, j;`) hoặc có khởi tạo (`int i = 2, k = (i + 5) * 4;`).
- **Phạm vi của biến:** Biến có tác dụng kể từ vị trí nó được khai báo cho đến hết khối lệnh `{ }` chứa nó.
- **Phép gán (`=`):** Cú pháp `tên_biến = biểu_thức;`. C++ cho phép **gán kép** (`i = j = k = 1;`) và đặt phép gán bên trong biểu thức (`n = 3 + (i = 2);` cho `i = 2` và `n = 5`).

### Câu hỏi

**Câu 1:** Lệnh `cout << "Hom nay\tnang\a\n";` sử dụng các hằng ký tự điều khiển nào?
- A. Ký tự kéo trang, dấu nháy đơn và xuống hàng
- B. Ký tự Tab (`\t`), tiếng chuông (`\a`) và xuống hàng (`\n`)
- C. Dấu gạch chéo ngược, dấu chấm hỏi và khoảng trắng
- D. Mã hệ 8 và mã hệ 16

**Đáp án đúng:** B

**Giải thích:** Trong chuỗi trên, `\t` là ký tự Tab, `\a` là ký tự phát tiếng chuông và `\n` là ký tự xuống hàng mới.

**Câu 2:** Sau khi thực hiện đoạn lệnh `int i, j, k, n; i = j = k = 1; n = 3 + (i = 2);`, giá trị của `i`, `j` và `n` lần lượt là bao nhiêu?
- A. `i = 1, j = 1, n = 4`
- B. `i = 2, j = 1, n = 5`
- C. `i = 2, j = 2, n = 5`
- D. `i = 1, j = 2, n = 3`

**Đáp án đúng:** B

**Giải thích:** Ban đầu `i = j = k = 1`. Ở câu lệnh `n = 3 + (i = 2);`, biểu thức `(i = 2)` gán `2` cho `i` và trả về `2`, nên `n = 3 + 2 = 5`, còn `j` vẫn bằng `1`.
