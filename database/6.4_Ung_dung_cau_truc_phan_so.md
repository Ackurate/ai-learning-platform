## Mục tiêu bài học {#muc-tieu-bai-hoc}

Sau khi học xong bài này, người học có thể:

- Xây dựng kiểu cấu trúc `Phanso` gồm hai thành phần nguyên: tử số và mẫu số.
- Cài đặt và sử dụng các hàm thao tác trên phân số: hàm nhập (có kiểm tra mẫu số khác 0) và hàm xuất phân số.
- Vận dụng hàm trả về kiểu cấu trúc để tính hiệu hai phân số.
- Cài đặt hàm tính thương hai phân số và kiểm tra điều kiện phân số chia khác 0.
- Kết hợp các hàm thành một chương trình C++ hoàn chỉnh, có cấu trúc rõ ràng và chặt chẽ.

## Khai báo cấu trúc phân số {#khai-bao-cau-truc-phan-so}

Một phân số trong toán học gồm hai thành phần: **tử số** và **mẫu số** (trong đó mẫu số bắt buộc phải khác 0).

Trong C++, ta sử dụng từ khóa `struct` để định nghĩa kiểu dữ liệu `Phanso` biểu diễn phân số:

```cpp
struct Phanso
{
    int tu;
    int mau;
};
```

Ý nghĩa các thành phần:

- `tu`: Tử số, kiểu số nguyên (`int`).
- `mau`: Mẫu số, kiểu số nguyên (`int`), có giá trị khác 0.

Ví dụ, phân số $\frac{3}{4}$ được biểu diễn bằng một biến `Phanso` có `tu = 3` và `mau = 4`:

```cpp
Phanso p = {3, 4};
```

Khi đó, ta dùng toán tử dấu chấm để truy xuất: `p.tu` bằng 3 và `p.mau` bằng 4.

### Câu hỏi kiểm tra {#cau-hoi-khai-bao-phan-so}

Cấu trúc `Phanso` dùng để biểu diễn một phân số cần có những thành phần cơ bản nào?

- A. Tử số và mẫu số
- B. Tử số và kết quả
- C. Mẫu số và phép tính
- D. Chỉ có tử số

**Đáp án: A.** Cấu trúc `Phanso` gồm hai thành phần nguyên là tử số `tu` và mẫu số `mau`.

## Nhập và xuất dữ liệu phân số {#nhap-xuat-phan-so}

### Hàm nhập phân số {#ham-nhap-phan-so}

Hàm `NhapPS()` dùng để nhập giá trị tử số và mẫu số từ bàn phím. Do mẫu số của một phân số hợp lệ phải khác 0, ta sử dụng vòng lặp `do...while` để yêu cầu người dùng nhập lại nếu nhập mẫu số bằng 0.

```cpp
void NhapPS(Phanso& p)
{
    cout << "Nhap tu so: ";
    cin >> p.tu;

    do
    {
        cout << "Nhap mau so khac 0: ";
        cin >> p.mau;
    } while (p.mau == 0);
}
```

> **Ghi nhớ:**
> Tham số `Phanso& p` được truyền bằng **tham chiếu** (`&`), cho phép hàm cập nhật trực tiếp dữ liệu vào biến phân số ban đầu được truyền từ hàm gọi. Nếu truyền theo giá trị (tham trị), mọi thay đổi chỉ có tác dụng trên bản sao cục bộ và dữ liệu sẽ bị mất khi hàm kết thúc.

### Hàm xuất phân số {#ham-xuat-phan-so}

Hàm `XuatPS()` hiển thị phân số ra màn hình theo định dạng chuẩn `tử_số/mẫu_số`.

```cpp
void XuatPS(Phanso p)
{
    cout << p.tu << "/" << p.mau;
}
```

Ví dụ, nếu `p.tu = 3` và `p.mau = 4`, lời gọi hàm `XuatPS(p)` sẽ in ra `3/4`. Do hàm này chỉ hiển thị dữ liệu mà không làm thay đổi giá trị của phân số, tham số `p` được truyền bằng giá trị.

### Câu hỏi kiểm tra {#cau-hoi-nhap-xuat-phan-so}

Vì sao hàm `NhapPS(Phanso& p)` sử dụng tham chiếu `&` cho tham số `p`?

- A. Để tạo một phân số mới trong bộ nhớ
- B. Để cập nhật trực tiếp giá trị nhập vào biến phân số ban đầu
- C. Để tự động rút gọn phân số sau khi nhập
- D. Để tránh việc người dùng nhập mẫu số bằng 0

**Đáp án: B.** Truyền bằng tham chiếu cho phép hàm cập nhật trực tiếp các thành phần của biến phân số ban đầu được truyền vào.

## Tính hiệu hai phân số {#tinh-hieu-hai-phan-so}

Cho hai phân số:

$$
a = \frac{a_t}{a_m}, \qquad b = \frac{b_t}{b_m}
$$

Hiệu của hai phân số được tính theo công thức quy đồng mẫu số:

$$
a - b = \frac{a_t \cdot b_m - a_m \cdot b_t}{a_m \cdot b_m}
$$

Hàm `Hieu()` nhận vào hai phân số `a`, `b`, tính toán tử số và mẫu số của hiệu, sau đó trả về kết quả là một biến cấu trúc `Phanso`:

```cpp
Phanso Hieu(Phanso a, Phanso b)
{
    Phanso kq;

    kq.tu = a.tu * b.mau - a.mau * b.tu;
    kq.mau = a.mau * b.mau;

    return kq;
}
```

**Ví dụ:** Với $a = \frac{3}{4}$ và $b = \frac{1}{2}$:

$$
a - b = \frac{3 \times 2 - 4 \times 1}{4 \times 2} = \frac{2}{8}
$$

Kết quả là `2/8`, tương đương $\frac{1}{4}$ (hàm trên chưa thực hiện rút gọn phân số).

### Câu hỏi kiểm tra {#cau-hoi-tinh-hieu}

Với hai phân số $a = \frac{3}{4}$ và $b = \frac{1}{2}$, tử số của kết quả khi gọi `Hieu(a, b)` là bao nhiêu?

- A. 1
- B. 2
- C. 4
- D. 8

**Đáp án: B.** Tử số được tính bằng công thức: $3 \times 2 - 4 \times 1 = 2$.

## Tính thương hai phân số {#tinh-thuong-hai-phan-so}

Thương của hai phân số được tính bằng cách nhân phân số thứ nhất với phân số nghịch đảo của phân số thứ hai:

$$
\frac{a}{b} = \frac{a_t \cdot b_m}{a_m \cdot b_t}
$$

**Điều kiện phép chia hợp lệ:**
Phép chia cho phân số $b$ chỉ hợp lệ khi $b \neq 0$. Vì mẫu số `b.mau` đã được đảm bảo khác 0 khi nhập, điều kiện $b \neq 0$ tương đương với việc tử số `b.tu` phải khác 0:

$$
b.tu \neq 0
$$

Hàm tính thương hai phân số:

```cpp
Phanso Thuong(Phanso a, Phanso b)
{
    Phanso kq;

    kq.tu = a.tu * b.mau;
    kq.mau = a.mau * b.tu;

    return kq;
}
```

Trước khi gọi hàm `Thuong()`, chương trình bắt buộc phải kiểm tra điều kiện `b.tu != 0`. Nếu tử số của phân số thứ hai bằng 0, không được thực hiện phép chia mà phải xuất thông báo lỗi phù hợp.

### Câu hỏi kiểm tra {#cau-hoi-tinh-thuong}

Điều kiện nào cần được kiểm tra trước khi gọi hàm `Thuong(a, b)` để tránh lỗi chia cho 0?

- A. `a.tu != 0`
- B. `a.mau != 0`
- C. `b.tu != 0`
- D. `b.mau == 0`

**Đáp án: C.** Phân số thứ hai bằng 0 khi tử số của nó bằng 0 (vì mẫu số luôn khác 0). Do đó cần kiểm tra `b.tu != 0` trước khi chia.

## Chương trình hoàn chỉnh {#chuong-trinh-hoan-chinh}

Dưới đây là chương trình C++ hoàn chỉnh kết hợp cấu trúc `Phanso` và các hàm để nhập hai phân số, xuất chúng, tính hiệu và tính thương nếu phép chia hợp lệ:

```cpp
#include <iostream>
using namespace std;

struct Phanso
{
    int tu;
    int mau;
};

void NhapPS(Phanso& p)
{
    cout << "Nhap tu so: ";
    cin >> p.tu;

    do
    {
        cout << "Nhap mau so khac 0: ";
        cin >> p.mau;
    } while (p.mau == 0);
}

void XuatPS(Phanso p)
{
    cout << p.tu << "/" << p.mau;
}

Phanso Hieu(Phanso a, Phanso b)
{
    Phanso kq;
    kq.tu = a.tu * b.mau - a.mau * b.tu;
    kq.mau = a.mau * b.mau;
    return kq;
}

Phanso Thuong(Phanso a, Phanso b)
{
    Phanso kq;
    kq.tu = a.tu * b.mau;
    kq.mau = a.mau * b.tu;
    return kq;
}

int main()
{
    Phanso a, b, h, t;

    cout << "Nhap phan so thu nhat:\n";
    NhapPS(a);

    cout << "Nhap phan so thu hai:\n";
    NhapPS(b);

    cout << "\nPhan so thu nhat: ";
    XuatPS(a);

    cout << "\nPhan so thu hai: ";
    XuatPS(b);

    h = Hieu(a, b);
    cout << "\nHieu hai phan so: ";
    XuatPS(h);

    if (b.tu != 0)
    {
        t = Thuong(a, b);
        cout << "\nThuong hai phan so: ";
        XuatPS(t);
    }
    else
    {
        cout << "\nKhong the chia cho phan so bang 0.";
    }

    cout << endl;
    return 0;
}
```

> **Lưu ý:**
> - Chương trình minh họa các thao tác cơ bản và chưa thực hiện rút gọn phân số kết quả về dạng tối giản.
> - Khi làm việc với kiểu `int`, các phép nhân chéo quy đồng có thể vượt giới hạn lưu trữ nếu nhập số quá lớn.

### Câu hỏi kiểm tra {#cau-hoi-chuong-trinh}

Trong chương trình hoàn chỉnh, nếu phân số thứ hai có tử số bằng 0, chương trình sẽ làm gì?

- A. Vẫn tính thương bình thường
- B. Tự động đổi tử số thành 1
- C. Thông báo không thể chia cho phân số bằng 0
- D. Dừng chương trình trước khi nhập phân số

**Đáp án: C.** Điều kiện `if (b.tu != 0)` ngăn chương trình thực hiện phép chia không hợp lệ và xuất thông báo lỗi tương ứng.

## Tổng kết kiến thức {#tong-ket-kien-thuc}

Các kiến thức trọng tâm cần nhớ khi làm việc với kiểu cấu trúc:

- Khai báo kiểu cấu trúc bằng từ khóa `struct`.
- Truy xuất các thành phần của biến cấu trúc bằng toán tử dấu chấm (`.`).
- Sử dụng tham số tham chiếu (`&`) trong hàm nhập để cập nhật trực tiếp dữ liệu vào biến cấu trúc ban đầu.
- Dùng hàm trả về kiểu cấu trúc để thực hiện các phép toán tính toán (như hiệu, thương phân số).
- Luôn kiểm tra điều kiện dữ liệu hợp lệ (mẫu số khác 0 khi nhập, tử số khác 0 khi chia) để chương trình vận hành an toàn và chính xác.
