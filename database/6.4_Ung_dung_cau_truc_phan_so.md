## 1. Khai báo cấu trúc phân số {#khai-bao-cau-truc-phan-so}

Cấu trúc `Phanso` dùng để biểu diễn một phân số gồm hai thành phần: tử số và mẫu số. Mẫu số phải khác 0.

```cpp
struct Phanso
{
    int tu;
    int mau;
};
```

Trong đó:

- `tu` là tử số.
- `mau` là mẫu số.

Ví dụ, phân số \(\frac{3}{4}\) được biểu diễn bằng một biến `Phanso` có `tu = 3` và `mau = 4`.

**Câu hỏi trắc nghiệm**

Cấu trúc `Phanso` cần có những thành phần nào?

A. Tử số và mẫu số  
B. Tử số và kết quả  
C. Mẫu số và phép tính  
D. Chỉ có tử số  

**Đáp án: A.** Cấu trúc `Phanso` gồm tử số `tu` và mẫu số `mau`.

## 2. Nhập và xuất phân số {#nhap-va-xuat-phan-so}

### 2.1. Hàm nhập phân số {#ham-nhap-phan-so}

Hàm `NhapPS()` dùng để nhập tử số và mẫu số. Chương trình yêu cầu nhập lại nếu mẫu số bằng 0.

```cpp
void NhapPS(Phanso& p)
{
    cout << "Nhap tu so: ";
    cin >> p.tu;

    do
    {
        cout << "Nhap mau so khac 0: ";
        cin >> p.mau;
    } while (p.mau == 0);
}
```

Tham số `Phanso& p` được truyền bằng tham chiếu, nên các giá trị nhập vào được lưu trực tiếp vào biến phân số ban đầu.

### 2.2. Hàm xuất phân số {#ham-xuat-phan-so}

Hàm `XuatPS()` hiển thị tử số và mẫu số theo dạng `tử số/mẫu số`.

```cpp
void XuatPS(Phanso p)
{
    cout << p.tu << "/" << p.mau;
}
```

Ví dụ, nếu `tu = 3` và `mau = 4`, kết quả hiển thị là `3/4`.

**Câu hỏi trắc nghiệm**

Vì sao hàm `NhapPS(Phanso& p)` sử dụng tham chiếu?

A. Để tạo một phân số mới  
B. Để thay đổi trực tiếp biến phân số được truyền vào  
C. Để tự động rút gọn phân số  
D. Để bỏ qua việc nhập dữ liệu  

**Đáp án: B.** Truyền bằng tham chiếu cho phép hàm cập nhật trực tiếp các thành phần của biến phân số ban đầu.

## 3. Tính hiệu hai phân số {#tinh-hieu-hai-phan-so}

Cho hai phân số:

\[
a=\frac{a_t}{a_m},\qquad b=\frac{b_t}{b_m}
\]

Hiệu hai phân số được tính theo công thức:

\[
a-b=\frac{a_t b_m-a_m b_t}{a_m b_m}
\]

Hàm `Hieu()` tính tử số và mẫu số của hiệu, sau đó trả về phân số kết quả.

```cpp
Phanso Hieu(Phanso a, Phanso b)
{
    Phanso kq;

    kq.tu = a.tu * b.mau - a.mau * b.tu;
    kq.mau = a.mau * b.mau;

    return kq;
}
```

Ví dụ, với \(a=\frac{3}{4}\) và \(b=\frac{1}{2}\):

\[
a-b=\frac{3\times2-4\times1}{4\times2}
=\frac{2}{8}
\]

Kết quả là `2/8`, tương đương \(\frac{1}{4}\). Hàm trên chưa thực hiện rút gọn phân số.

**Câu hỏi trắc nghiệm**

Với \(a=\frac{3}{4}\) và \(b=\frac{1}{2}\), tử số của kết quả `Hieu(a, b)` là bao nhiêu?

A. 1  
B. 2  
C. 4  
D. 8  

**Đáp án: B.** Tử số được tính bằng \(3\times2-4\times1=2\).

## 4. Tính thương hai phân số {#tinh-thuong-hai-phan-so}

Thương hai phân số được tính theo công thức:

\[
\frac{a}{b}=\frac{a_t b_m}{a_m b_t}
\]

Điều kiện để phép chia hợp lệ là phân số \(b\) khác 0. Vì mẫu số của một phân số hợp lệ luôn khác 0, điều này tương đương với việc tử số `b.tu` phải khác 0.

```cpp
Phanso Thuong(Phanso a, Phanso b)
{
    Phanso kq;

    kq.tu = a.tu * b.mau;
    kq.mau = a.mau * b.tu;

    return kq;
}
```

Trước khi gọi `Thuong()`, cần kiểm tra `b.tu != 0`. Nếu tử số của phân số thứ hai bằng 0, không được thực hiện phép chia.

**Câu hỏi trắc nghiệm**

Điều kiện nào cần được kiểm tra trước khi gọi `Thuong(a, b)`?

A. `a.tu != 0`  
B. `a.mau != 0`  
C. `b.tu != 0`  
D. `b.mau == 0`  

**Đáp án: C.** Phân số thứ hai bằng 0 khi tử số bằng 0 và mẫu số khác 0, nên cần kiểm tra `b.tu != 0`.

## 5. Chương trình hoàn chỉnh {#chuong-trinh-hoan-chinh}

Chương trình dưới đây nhập hai phân số, xuất chúng, tính hiệu và tính thương nếu phép chia hợp lệ.

```cpp
#include <iostream>
using namespace std;

struct Phanso
{
    int tu;
    int mau;
};

void NhapPS(Phanso& p)
{
    cout << "Nhap tu so: ";
    cin >> p.tu;

    do
    {
        cout << "Nhap mau so khac 0: ";
        cin >> p.mau;
    } while (p.mau == 0);
}

void XuatPS(Phanso p)
{
    cout << p.tu << "/" << p.mau;
}

Phanso Hieu(Phanso a, Phanso b)
{
    Phanso kq;
    kq.tu = a.tu * b.mau - a.mau * b.tu;
    kq.mau = a.mau * b.mau;

    return kq;
}

Phanso Thuong(Phanso a, Phanso b)
{
    Phanso kq;
    kq.tu = a.tu * b.mau;
    kq.mau = a.mau * b.tu;

    return kq;
}

int main()
{
    Phanso a, b, h, t;

    cout << "Nhap phan so thu nhat:\n";
    NhapPS(a);

    cout << "Nhap phan so thu hai:\n";
    NhapPS(b);

    cout << "Phan so thu nhat: ";
    XuatPS(a);

    cout << "\nPhan so thu hai: ";
    XuatPS(b);

    h = Hieu(a, b);
    cout << "\nHieu hai phan so: ";
    XuatPS(h);

    if (b.tu != 0)
    {
        t = Thuong(a, b);
        cout << "\nThuong hai phan so: ";
        XuatPS(t);
    }
    else
    {
        cout << "\nKhong the chia cho phan so bang 0.";
    }

    return 0;
}
```

**Lưu ý:** Chương trình chưa rút gọn kết quả phân số. Ngoài ra, với dữ liệu nguyên kiểu `int`, các phép nhân có thể vượt giới hạn lưu trữ nếu nhập số quá lớn.

**Câu hỏi trắc nghiệm**

Nếu phân số thứ hai có tử số bằng 0, chương trình sẽ làm gì?

A. Vẫn tính thương bình thường  
B. Tự động đổi tử số thành 1  
C. Thông báo không thể chia cho phân số bằng 0  
D. Dừng trước khi nhập hai phân số  

**Đáp án: C.** Điều kiện `if (b.tu != 0)` ngăn chương trình thực hiện phép chia không hợp lệ.

## 6. Kết luận {#ket-luan}

Qua bài học, chúng ta đã vận dụng cấu trúc để biểu diễn phân số và sử dụng hàm để nhập, xuất, tính hiệu và tính thương hai phân số.

Các kiến thức cần nhớ:

- Khai báo kiểu cấu trúc bằng `struct`.
- Truy xuất thành phần cấu trúc bằng dấu chấm (`.`).
- Sử dụng tham chiếu để cập nhật dữ liệu trong hàm nhập.
- Dùng hàm để thực hiện các phép tính trên cấu trúc.
- Kiểm tra điều kiện trước khi thực hiện phép chia để tránh chia cho 0.

**Câu hỏi trắc nghiệm**

Dấu chấm (`.`) trong biểu thức `p.tu` dùng để làm gì?

A. Gọi hàm  
B. Truy xuất thành phần `tu` của biến cấu trúc `p`  
C. Khai báo kiểu cấu trúc  
D. So sánh hai phân số  

**Đáp án: B.** Dấu chấm dùng để truy xuất một thành phần của biến cấu trúc.

## 7. Câu hỏi ôn tập {#cau-hoi-on-tap}

**Câu 1.** Với cấu trúc `Phanso` gồm hai thành phần `tu` và `mau`, hàm nào dưới đây dùng để nhập dữ liệu trực tiếp vào biến phân số được truyền vào?

A. `void NhapPS(Phanso& p)`  
B. `void XuatPS(Phanso p)`  
C. `Phanso Hieu(Phanso a, Phanso b)`  
D. `Phanso Thuong(Phanso a, Phanso b)`  

**Đáp án: A.** Hàm `NhapPS()` nhận tham số tham chiếu nên có thể cập nhật trực tiếp tử số và mẫu số của biến được truyền vào.

**Câu 2.** Vì sao cần kiểm tra `b.tu != 0` trước khi tính thương hai phân số?

A. Để mẫu số của phân số thứ nhất luôn bằng 0  
B. Để tự động rút gọn kết quả  
C. Để tránh chia cho phân số thứ hai bằng 0  
D. Để thay đổi tử số của phân số thứ hai  

**Đáp án: C.** Nếu `b.tu == 0`, phân số thứ hai bằng 0, nên phép chia không hợp lệ.
