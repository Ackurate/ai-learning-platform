## Cấu trúc lặp do ... while {#cau-truc-lap-do-while}

Cấu trúc `do ... while` thực hiện khối lệnh lặp trước rồi mới kiểm tra điều kiện lặp ở cuối mỗi vòng.

**Cú pháp:**
```cpp
do {
    khối_lệnh_lặp;
} while (điều_kiện);
```

**Cách thực hiện và đặc điểm:**
- Đầu tiên chương trình thực hiện `khối_lệnh_lặp`, tiếp theo mới kiểm tra `điều_kiện`: nếu còn đúng thì quay lại thực hiện khối lệnh lặp; nếu sai thì dừng.
- Điểm khác biệt cơ bản so với `while`: khối lệnh trong `do ... while` luôn được thực hiện **ít nhất một lần** vì điều kiện được kiểm tra sau.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 17, i = 1;
    do {
        i++;
    } while (i <= n / 2 && n % i != 0);
    if (i > n / 2)
        cout << n << " la so nguyen to" << endl;
    else
        cout << n << " la hop so" << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Điểm khác biệt cơ bản nhất giữa vòng lặp `while` và vòng lặp `do ... while` là gì?
- A. `while` chỉ lặp được với số nguyên, còn `do ... while` lặp được với số thực.
- B. Khối lệnh trong `do ... while` được thực hiện ít nhất 1 lần, còn khối lệnh trong `while` có thể không được thực hiện lần nào.
- C. `do ... while` không cần điều kiện dừng, còn `while` bắt buộc phải có điều kiện dừng.
- D. `while` không dùng được lệnh `break`, còn `do ... while` dùng được lệnh `break`.

**Đáp án đúng:** B

**Giải thích:** `do ... while` thực hiện khối lệnh trước rồi mới kiểm tra điều kiện nên luôn chạy ít nhất 1 lần, còn `while` kiểm tra điều kiện trước nên có thể chạy 0 lần.

**Câu 2:** Với `int x = 5;`, sau khi chạy đoạn code `do { x = x + 2; } while (x < 5);`, giá trị của `x` bằng bao nhiêu?
- A. `5`
- B. `7`
- C. `9`
- D. Lặp vô tận

**Đáp án đúng:** B

**Giải thích:** Khối lệnh trong `do` chạy lần đầu tiên tăng `x` từ `5` lên `7`, sau đó kiểm tra điều kiện `7 < 5` thấy sai nên dừng vòng lặp. Kết quả `x = 7`.
