## Nhập và xuất dữ liệu trong C++ {#nhap-va-xuat-du-lieu-trong-cpp}

Để sử dụng lệnh nhập `cin >>` và lệnh xuất `cout <<`, đầu chương trình phải khai báo `#include <iostream>` và `using namespace std;`.

**1. Nhập dữ liệu từ bàn phím (`cin >>`):**
```cpp
cin >> cd >> cr;
```
Khi gặp lệnh `cin >>`, chương trình tạm dừng chờ người dùng nhập giá trị từ bàn phím. Khi nhập nhiều biến, các giá trị phải cách nhau bởi ít nhất một **dấu trắng** (phím `Spacebar`, phím `Tab` hoặc phím `Enter`).

**2. Xuất dữ liệu ra màn hình (`cout <<`):**
```cpp
cout << "Dien tich = " << cd * cr << '\n' << "Chu vi = " << 2 * (cd + cr) << endl;
```
Có thể xuất chuỗi ký tự, biến hoặc biểu thức tính toán. Ký tự `'\n'` và `endl` đều dùng để xuống hàng mới.

**3. Định dạng thông tin xuất với thư viện `#include <iomanip>`:**
- `endl`: Xuống dòng mới (tương đương `'\n'`).
- `setw(n)`: Quy định độ rộng vùng in là `n` cột màn hình (căn lề phải, chừa khoảng trắng bên trái nếu giá trị ngắn hơn `n`).
- `setprecision(n)`: Chỉ định số chữ số hiển thị là `n` (có làm tròn).
- `setiosflags(ios::showpoint)`: Giữ cố định định dạng số thực cho mọi hàng in tiếp theo.

**4. Lưu ý khi nhập ký tự và chuỗi:**
Toán tử `cin >> x` để lại ký tự xuống hàng (`Enter`) trong bộ nhớ đệm, làm trôi các lệnh `cin.get(c)` (nhập 1 ký tự), `cin.getline(s, n)` (nhập tối đa `n - 1` ký tự) hoặc `gets(st)` ở phía sau. Vì vậy cần gọi **`cin.ignore(1);`** trước các lệnh này để lấy bỏ ký tự xuống hàng còn sót lại.

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int x;
    char c;
    cout << "Nhap so nguyen x = ";
    cin >> x;
    cin.ignore(1); // Xóa ký tự Enter còn sót trong bộ đệm
    cout << "Nhap ky tu c = ";
    cin.get(c);
    cout << "Ket qua: x = " << setw(5) << x << ", c = " << c << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Khi thực hiện lệnh `cin >> cd >> cr;`, nếu người dùng gõ `23 11` rồi nhấn Enter thì hai biến `cd` và `cr` nhận giá trị như thế nào?
- A. `cd = 2311`, máy chờ nhập tiếp `cr`
- B. `cd = 23` và `cr = 11`
- C. `cd = 11` và `cr = 23`
- D. Báo lỗi vì không dùng dấu phẩy ngăn cách

**Đáp án đúng:** B

**Giải thích:** Dấu cách giữa `23` và `11` là dấu trắng hợp lệ giúp phân tách hai giá trị nhập vào, nên `cd` nhận `23` và `cr` nhận `11`.

**Câu 2:** Lệnh nào dùng để loại bỏ ký tự xuống hàng còn sót lại trong bộ nhớ đệm sau lệnh `cin >> x;` trước khi gọi `cin.get(c);`?
- A. `cin.clear();`
- B. `cin.ignore(1);`
- C. `setw(1);`
- D. `setprecision(1);`

**Đáp án đúng:** B

**Giải thích:** Phương thức `cin.ignore(1)` lấy bỏ 1 ký tự (ký tự xuống hàng) còn sót lại trong bộ đệm bàn phím để lệnh `cin.get(c)` hoặc `cin.getline(s, n)` không bị trôi.
