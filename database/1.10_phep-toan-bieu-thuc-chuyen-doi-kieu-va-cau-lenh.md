## Phép toán, biểu thức, chuyển đổi kiểu và câu lệnh {#phep-toan-bieu-thuc-chuyen-doi-kieu-va-cau-lenh}

**1. Các phép toán trong C++:**
- **Phép toán số học (`+`, `-`, `*`, `/`, `%`):** Phép chia `/` giữa hai số nguyên chỉ lấy phần nguyên (`13 / 5 = 2`), nếu có ít nhất 1 toán hạng thực thì cho kết quả thực (`13.0 / 5 = 2.6`). Phép `%` lấy phần dư của phép chia hai số nguyên (`13 % 5 = 3`, `5 % 13 = 5`).
- **Phép toán tự tăng, tự giảm (`++i`, `i++`, `--i`, `i--`):**
  - `++i` (tăng trước): tăng `i` lên 1 trước rồi mới tham gia tính toán trong biểu thức.
  - `i++` (tăng sau): lấy giá trị `i` cũ để tính biểu thức trước, sau đó mới tăng `i` lên 1.
- **Phép toán so sánh (`==`, `!=`, `>`, `<`, `>=`, `<=`) và logic (`&&`, `||`, `!`):** Trả về `1` (đúng) hoặc `0` (sai). C++ đánh giá biểu thức logic từ trái sang phải và **dừng ngay khi đã biết kết quả**.
- **Phép gán có điều kiện và gán thu gọn:**
  - Gán có điều kiện: `biến = (Điều_kiện) ? a : b;` (nếu `Điều_kiện` đúng thì gán `a`, sai thì gán `b`).
  - Gán thu gọn: `x += 2` tương đương `x = x + 2`; `x /= 2` tương đương `x = x / 2`.

**2. Thứ tự ưu tiên của các phép toán:**
1. Các biểu thức trong cặp ngoặc đơn `( )` (ngoặc trong cùng tính trước).
2. Các phép toán 1 ngôi (`++`, `--`, `!`, ...).
3. Các phép toán số học (`*`, `/`, `%` trước `+`, `-`).
4. Các phép toán so sánh và logic (`&&` thuộc lớp nhân, `||` thuộc lớp cộng).
5. Các phép gán (thực hiện từ phải sang trái).

**3. Chuyển đổi kiểu dữ liệu:**
- **Chuyển kiểu tự động (từ thấp lên cao):** `char <-> int -> long int -> float -> double`.
- **Ép kiểu (từ cao xuống thấp):** `(tên_kiểu)biểu_thức` hoặc `tên_kiểu(biểu_thức)`. Ép kiểu số thực `x` về `int(x)` sẽ cắt bỏ phần lẻ, chỉ giữ phần nguyên.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 3, j = 15;
    int a = ++i + 5; // i = 4, a = 9
    int b = j++ + 5; // b = 20, j = 16
    int x = (3 + 4 < 7) ? 10 : 20; // 7 < 7 sai nên x = 20
    cout << "a = " << a << ", b = " << b << ", x = " << x << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Với giả thiết `int i = 3;`, sau khi thực hiện câu lệnh `int j = ++i + 5;`, giá trị của `i` và `j` là bao nhiêu?
- A. `i = 4, j = 9`
- B. `i = 4, j = 8`
- C. `i = 3, j = 8`
- D. `i = 3, j = 9`

**Đáp án đúng:** A

**Giải thích:** Toán tử `++i` là tăng trước (`i = i + 1 = 4`), sau đó mới tính `j = i + 5 = 4 + 5 = 9`.

**Câu 2:** Trong C++, thứ tự ưu tiên nào sau đây được sắp xếp ĐÚNG từ cao xuống thấp?
- A. Phép gán -> Phép so sánh -> Phép toán số học -> Dấu ngoặc `()`
- B. Dấu ngoặc `()` -> Phép toán 1 ngôi -> Phép toán số học -> Phép so sánh, logic -> Phép gán
- C. Phép toán số học -> Dấu ngoặc `()` -> Phép gán -> Phép logic
- D. Phép so sánh -> Phép toán 1 ngôi -> Dấu ngoặc `()` -> Phép gán

**Đáp án đúng:** B

**Giải thích:** Theo mục 1.8.3.1 giáo trình, thứ tự ưu tiên từ cao xuống thấp là: (1) Biểu thức trong ngoặc `()` -> (2) Phép toán 1 ngôi -> (3) Phép toán số học -> (4) Phép toán so sánh, logic -> (5) Phép gán.
