## Cấu trúc lựa chọn switch

Khi cần rẽ theo nhiều nhánh dựa trên giá trị của một biểu thức, câu lệnh `switch` giúp chương trình gọn gàng và dễ đọc hơn so với việc lồng nhiều lệnh `if`.

**Cú pháp:**
```cpp
switch (biểu_thức_điều_khiển) {
    case biểu_thức_1: dãy_lệnh_1; break;
    case biểu_thức_2: dãy_lệnh_2; break;
    default: dãy_lệnh_n_cộng_1;
}
```

**Quy tắc và cách thực hiện:**
- **Biểu thức điều khiển** và các **`biểu_thức_i`** sau `case` bắt buộc phải có kiểu **nguyên** hoặc **ký tự**.
- Các dãy lệnh trong mỗi `case` có thể rỗng và không cần bao bởi cặp ngoặc móc `{ }`.
- Chương trình tính giá trị của biểu thức điều khiển rồi so sánh lần lượt với các `biểu_thức_i`. Khi gặp `biểu_thức_i` bằng giá trị biểu thức điều khiển, chương trình thực hiện `dãy_lệnh_i` và **tiếp tục thực hiện tất cả các dãy lệnh còn lại bên dưới** cho đến hết `switch` nếu không có lệnh `break;`.
- Nếu không khớp với nhánh `case` nào thì chương trình thực hiện nhánh `default` (nếu có).

```cpp
#include <iostream>
using namespace std;

int main() {
    int th, n;
    cout << "Nhap vao mot thang bat ky : ";
    cin >> th;
    switch (th) {
        case 1: case 3: case 5: case 7: case 8: case 10: case 12:
            cout << "Thang nay co 31 ngay"; break;
        case 4: case 6: case 9: case 11:
            cout << "Thang nay co 30 ngay"; break;
        case 2:
            cout << "Cho biet nam nao : ";
            cin >> n;
            if (n % 4 == 0 && n % 100 != 0 || n % 400 == 0)
                cout << "Thang nay co 29 ngay";
            else
                cout << "Thang nay co 28 ngay";
            break;
        default:
            cout << "Ban da nhap so thang khong hop le";
    }
    return 0;
}
```

### Câu hỏi

**Câu 1:** Trong cấu trúc `switch`, kiểu dữ liệu của biểu thức điều khiển phải là kiểu nào?
- A. Kiểu số thực (`float` hoặc `double`)
- B. Kiểu số nguyên hoặc kiểu ký tự
- C. Kiểu chuỗi ký tự
- D. Chỉ kiểu `bool`

**Đáp án đúng:** B

**Giải thích:** Biểu thức điều khiển của `switch` và các biểu thức hằng sau `case` bắt buộc phải có kiểu nguyên hoặc ký tự.

**Câu 2:** Đoạn code sau in ra màn hình kết quả gì?

```cpp
int k = 1;
switch (k) {
    case 1: cout << "Mot ";
    case 2: cout << "Hai "; break;
    default: cout << "Khac";
}
```

- A. `Mot `
- B. `Mot Hai `
- C. `Mot Hai Khac`
- D. `Hai `

**Đáp án đúng:** B

**Giải thích:** Khi `k = 1`, chương trình vào `case 1` in `"Mot "`. Do cuối `case 1` không có lệnh `break;`, chương trình tiếp tục thực hiện lệnh của `case 2` in thêm `"Hai "` rồi mới gặp `break;` và thoát khỏi `switch`.
