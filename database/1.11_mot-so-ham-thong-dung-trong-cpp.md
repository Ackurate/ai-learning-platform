## Một số hàm thông dụng trong C++ {#mot-so-ham-thong-dung-trong-cpp}

Giáo trình giới thiệu 3 nhóm hàm chuẩn thường dùng trong C++:

| Nhóm hàm | Thư viện | Các hàm tiêu biểu và công dụng |
| :--- | :--- | :--- |
| **Nhóm hàm toán học** | `<math.h>` | `abs(x)`, `labs(x)`, `fabs(x)` (trị tuyệt đối nguyên, nguyên dài, thực); `pow(x, y)` ($x^y$); `exp(x)` ($e^x$); `log(x)` ($\ln x$), `log10(x)` ($\log x$); `sqrt(x)` ($\sqrt{x}$); `sin(x)`, `cos(x)`, `tan(x)`, `asin(x)`, `acos(x)`, `atan(x)` |
| **Nhóm hàm kiểm tra ký tự** | `<ctype.h>` | `isalnum(kt)` (chữ cái hoặc số); `isalpha(kt)` (chữ cái); `isdigit(kt)` (chữ số); `islower(kt)` (chữ thường `a..z`); `isupper(kt)` (chữ hoa `A..Z`); `isspace(kt)` (ký tự trống) |
| **Nhóm hàm chuyển đổi dữ liệu** | `<ctype.h>` | `toupper(c)` (đổi sang chữ hoa); `tolower(c)` (đổi sang chữ thường); `atof(s)` (chuỗi sang `double`); `atoi(s)` (chuỗi sang `int`); `atol(s)` (chuỗi sang `long`) |

```cpp
#include <iostream>
#include <math.h>
#include <ctype.h>
using namespace std;

int main() {
    cout << "2 mu 3 = " << pow(2, 3) << ", Can bac hai cua 16 = " << sqrt(16) << endl;
    char kt = 'g';
    if (islower(kt))
        cout << "In hoa: " << char(toupper(kt)) << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Trong thư viện `<math.h>`, cặp hàm nào dùng để tính trị tuyệt đối của một số thực `x` và tính $e^x$?
- A. `abs(x)` và `pow(x, e)`
- B. `fabs(x)` và `exp(x)`
- C. `labs(x)` và `log(x)`
- D. `sqrt(x)` và `log10(x)`

**Đáp án đúng:** B

**Giải thích:** `fabs(x)` trả về giá trị tuyệt đối của số thực `x` (còn `abs(x)` dùng cho số nguyên, `labs(x)` cho số nguyên dài), và `exp(x)` trả về giá trị $e^x$.

**Câu 2:** Hàm nào trong `<ctype.h>` kiểm tra xem ký tự `kt` có phải là chữ cái thường (`a..z`) hay không?
- A. `isalpha(kt)`
- B. `islower(kt)`
- C. `tolower(kt)`
- D. `isdigit(kt)`

**Đáp án đúng:** B

**Giải thích:** `islower(kt)` kiểm tra `kt` có phải là chữ cái thường hay không, còn `tolower(c)` là hàm chuyển từ chữ hoa sang chữ thường.
