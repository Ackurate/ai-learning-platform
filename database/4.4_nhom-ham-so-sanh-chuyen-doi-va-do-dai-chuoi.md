## Nhóm hàm so sánh, chuyển đổi chữ hoa/thường và lấy độ dài chuỗi

Trong thư viện `<string.h>`, các hàm so sánh, chuyển đổi chữ và lấy độ dài chuỗi gồm:

| Hàm | Chức năng chi tiết |
| :--- | :--- |
| `strcmp(s, t)` | So sánh 2 chuỗi `s` và `t` theo mã ASCII (**có** phân biệt hoa/thường: `'A' < 'a'` vì `65 < 97`). Trả về `-1` nếu `s < t`, `0` nếu `s == t`, `1` nếu `s > t` |
| `strncmp(s, t, n)` | Giống `strcmp(s, t)` nhưng chỉ so sánh tối đa `n` ký tự đầu tiên của hai chuỗi |
| `strcmpi(s, t)` | Giống `strcmp(s, t)` nhưng **không** phân biệt chữ hoa và chữ thường |
| `strupr(s)` | Đổi toàn bộ chuỗi `s` thành chữ in hoa và trả về chuỗi đó |
| `strlwr(s)` | Đổi toàn bộ chuỗi `s` thành chữ in thường và trả về chuỗi đó |
| `strlen(s)` | Trả về độ dài thực sự của chuỗi `s` (số ký tự trước `'\0'`) |

```cpp
#include <iostream>
#include <string.h>
using namespace std;

int main() {
    char s[] = "Ha Noi", t[] = "ha noi";
    cout << strcmp(s, t) << endl;     // In ra -1 (vì 'H' < 'h')
    cout << strcmpi(s, t) << endl;    // In ra 0  (không phân biệt hoa/thường)
    cout << strlen(s) << endl;        // In ra 6
    return 0;
}
```

### Câu hỏi

**Câu 1:** Đoạn code `char s[] = "Ha Noi", t[] = "Ha noi"; cout << strcmp(s, t) << " " << strncmp(s, t, 3);` in ra kết quả gì?
- A. `0 0`
- B. `-1 0`
- C. `1 -1`
- D. `-1 -1`

**Đáp án đúng:** B

**Giải thích:** `strcmp("Ha Noi", "Ha noi")` trả về `-1` vì ký tự khác nhau đầu tiên là `'N'` (`78`) nhỏ hơn `'n'` (`110`). Còn `strncmp(s, t, 3)` chỉ so sánh 3 ký tự đầu `"Ha "` của cả 2 chuỗi nên bằng nhau và trả về `0`.

**Câu 2:** Sau khi thực hiện `char s[10] = "Ha Noi"; strupr(s);`, giá trị của `s` và `strlen(s)` lần lượt là gì?
- A. `"ha noi"` và `6`
- B. `"HA NOI"` và `6`
- C. `"HA NOI"` và `7`
- D. `"Ha Noi"` và `10`

**Đáp án đúng:** B

**Giải thích:** Hàm `strupr(s)` đổi trực tiếp chuỗi `s` thành chữ in hoa `"HA NOI"`, và `strlen(s)` trả về độ dài thực sự của chuỗi là `6` ký tự (không tính `'\0'`).
