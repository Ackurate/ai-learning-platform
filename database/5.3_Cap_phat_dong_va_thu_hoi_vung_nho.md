## Mục tiêu bài học {#muc-tieu-bai-hoc}

Sau bài học này, người học có thể:

- Hiểu khái niệm cấp phát động và lợi ích của việc cấp phát vùng nhớ khi chương trình chạy.
- Biết sử dụng toán tử `new` để cấp phát vùng nhớ.
- Phân biệt cách sử dụng `delete` và `delete[]` để thu hồi vùng nhớ.
- Biết vận dụng con trỏ và cấp phát động để nhập, xuất và sắp xếp một dãy số nguyên.

## Cấp phát động {#cap-phat-dong}

Khi chương trình chạy, bộ nhớ dành cho các biến khai báo thông thường được xác định theo cách khai báo. Nếu khai báo một mảng có kích thước cố định, chương trình phải sử dụng vùng nhớ theo kích thước đã định. Mảng quá nhỏ có thể không đủ chứa dữ liệu, còn mảng quá lớn có thể gây lãng phí.

**Cấp phát động** cho phép chương trình yêu cầu vùng nhớ theo nhu cầu khi chạy. Trong C++, có thể dùng `new` để cấp phát vùng nhớ và `delete` hoặc `delete[]` để thu hồi vùng nhớ khi không còn cần sử dụng.

### Câu hỏi

**Câu 1:** Cấp phát động có đặc điểm nào sau đây?

- A. Chỉ có thể thực hiện trước khi chương trình chạy.
- B. Cho phép yêu cầu vùng nhớ trong khi chương trình đang chạy.
- C. Chỉ dùng để lưu ký tự.
- D. Không cần sử dụng con trỏ.

**Đáp án đúng:** B

**Giải thích:** Cấp phát động cho phép chương trình yêu cầu vùng nhớ trong thời gian chạy, phù hợp khi số lượng dữ liệu chỉ được xác định khi người dùng nhập hoặc khi chương trình xử lý.

## Toán tử cấp phát vùng nhớ `new` {#toan-tu-cap-phat-new}

Cú pháp cấp phát vùng nhớ cho một đối tượng:

```cpp
p = new <kieu>;
```

Cú pháp cấp phát vùng nhớ cho một mảng gồm `n` phần tử:

```cpp
p = new <kieu>[n];
```

Trong đó:

- `p` là biến con trỏ dùng để lưu địa chỉ vùng nhớ được cấp phát.
- `new <kieu>` cấp phát vùng nhớ cho một đối tượng.
- `new <kieu>[n]` cấp phát vùng nhớ cho `n` phần tử cùng kiểu dữ liệu.

Ví dụ:

```cpp
#include <iostream>
using namespace std;

int main()
{
    float *p;
    int n;

    cout << "So luong can cap phat: ";
    cin >> n;

    if (n <= 0)
    {
        cout << "So luong khong hop le!";
        return 0;
    }

    p = new float[n];

    cout << "Cap phat thanh cong!";

    delete[] p;

    return 0;
}
```

Trong ví dụ trên, người dùng nhập số lượng phần tử cần cấp phát. Chương trình sử dụng `new float[n]` để cấp phát vùng nhớ cho `n` phần tử kiểu `float`. Sau khi sử dụng xong, chương trình dùng `delete[] p` để thu hồi vùng nhớ.

### Câu hỏi

**Câu 1:** Câu lệnh nào cấp phát vùng nhớ động cho một mảng gồm `n` số nguyên?

- A. `int p[n];`
- B. `p = new int;`
- C. `p = new int[n];`
- D. `new[p] = int[n];`

**Đáp án đúng:** C

**Giải thích:** Cú pháp `new int[n]` cấp phát vùng nhớ cho một mảng gồm `n` phần tử kiểu `int`. Địa chỉ phần tử đầu tiên được gán cho con trỏ `p`.

## Toán tử thu hồi vùng nhớ `delete` {#toan-tu-thu-hoi-delete}

Cú pháp thu hồi vùng nhớ:

```cpp
delete p;
delete[] p;
```

Trong đó:

- `delete p` dùng để thu hồi vùng nhớ đã cấp phát cho một đối tượng bằng `new`.
- `delete[] p` dùng để thu hồi vùng nhớ của một mảng được cấp phát bằng `new[]`.

Cần thu hồi vùng nhớ động khi không còn sử dụng để tránh giữ lại vùng nhớ không cần thiết. Phải dùng đúng dạng thu hồi tương ứng với cách cấp phát.

### Câu hỏi

**Câu 1:** Nếu cấp phát một mảng bằng `p = new int[10];`, nên dùng câu lệnh nào để thu hồi vùng nhớ?

- A. `delete p;`
- B. `delete[] p;`
- C. `new[] p;`
- D. `free(p);`

**Đáp án đúng:** B

**Giải thích:** Mảng được cấp phát bằng `new[]` cần được thu hồi bằng `delete[]`. Dùng sai dạng thu hồi có thể dẫn đến hành vi không xác định.

## Ví dụ minh họa: Nhập và sắp xếp dãy số {#vi-du-nhap-va-sap-xep-day-so}

### Đề bài {#de-bai}

Nhập một dãy gồm `n` số nguyên, in dãy vừa nhập, sắp xếp dãy theo thứ tự tăng dần rồi in kết quả. Sử dụng cấp phát động để cấp đủ vùng nhớ cho `n` phần tử.

### Code C++ {#code-cpp}

```cpp
#include <iostream>
using namespace std;

int main()
{
    int *head, *p, *q, n, tam;

    cout << "Cho biet so phan tu cua day: ";
    cin >> n;

    if (n <= 0)
    {
        cout << "So phan tu khong hop le!";
        return 0;
    }

    head = new int[n];

    for (p = head; p < head + n; p++)
    {
        cout << "Nhap phan tu thu " << p - head + 1 << ": ";
        cin >> *p;
    }

    cout << "Day vua nhap la: " << endl;

    for (p = head; p < head + n; p++)
        cout << *p << '\t';

    cout << endl;

    for (p = head; p < head + n - 1; p++)
    {
        for (q = p + 1; q < head + n; q++)
        {
            if (*p > *q)
            {
                tam = *p;
                *p = *q;
                *q = tam;
            }
        }
    }

    cout << "Day sau khi sap xep la: " << endl;

    for (p = head; p < head + n; p++)
        cout << *p << '\t';

    cout << endl;

    delete[] head;

    return 0;
}
```

### Giải thích chương trình {#giai-thich-chuong-trinh}

1. Nhập số phần tử `n` của dãy và kiểm tra số lượng có hợp lệ hay không.
2. Dùng `new int[n]` để cấp phát vùng nhớ cho `n` số nguyên.
3. Dùng con trỏ `p` để nhập và in các phần tử.
4. Dùng hai con trỏ `p` và `q` để duyệt, so sánh các phần tử và đổi chỗ khi phần tử đứng trước lớn hơn phần tử đứng sau.
5. In dãy sau khi sắp xếp tăng dần.
6. Dùng `delete[] head` để thu hồi vùng nhớ đã cấp phát.

### Câu hỏi

**Câu 1:** Trong chương trình sắp xếp dãy số, câu lệnh `delete[] head;` có tác dụng gì?

- A. Xóa toàn bộ biến `head` khỏi chương trình.
- B. Sắp xếp dãy số theo thứ tự giảm dần.
- C. Thu hồi vùng nhớ động đã cấp phát cho mảng.
- D. Gán giá trị `0` cho tất cả phần tử của mảng.

**Đáp án đúng:** C

**Giải thích:** `head` lưu địa chỉ vùng nhớ được cấp phát bằng `new int[n]`. Câu lệnh `delete[] head;` thu hồi vùng nhớ của mảng khi không còn cần sử dụng.

## Câu hỏi ôn tập {#cau-hoi-on-tap}

**Câu 1:** Câu lệnh nào dùng để cấp phát động vùng nhớ cho một đối tượng kiểu `float`?

- A. `float p = new;`
- B. `p = new float;`
- C. `p = new float[ ];`
- D. `delete p;`

**Đáp án đúng:** B

**Giải thích:** `new float` cấp phát vùng nhớ cho một đối tượng kiểu `float` và trả về địa chỉ để gán cho con trỏ `p`.

**Câu 2:** Cho đoạn code sau:

```cpp
int *p = new int[5];
p[0] = 10;
delete[] p;
```

Câu lệnh nào thu hồi vùng nhớ đúng với cách cấp phát đã sử dụng?

- A. `delete p;`
- B. `delete[] p;`
- C. `p = 0;`
- D. `new int[5];`

**Đáp án đúng:** B

**Giải thích:** Mảng được cấp phát bằng `new int[5]`, nên phải dùng `delete[] p;` để thu hồi vùng nhớ tương ứng.
