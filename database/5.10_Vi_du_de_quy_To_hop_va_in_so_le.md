## Mục tiêu bài học {#muc-tieu-bai-hoc}

Sau khi học xong bài này, người học có thể:

- Hiểu cách sử dụng đệ quy để tính tổ hợp.
- Hiểu cách sử dụng đệ quy để in các số lẻ theo thứ tự giảm dần.
- Biết cách sử dụng thêm đối số để in các số lẻ theo thứ tự tăng dần.

## Ví dụ 3: Tính tổ hợp {#tinh-to-hop}

Công thức đệ quy tính tổ hợp chập \(k\) của \(n\) là:

\[
C_n^k =
\begin{cases}
1, & k=0 \text{ hoặc } k=n\\
C_{n-1}^{k-1}+C_{n-1}^{k}, & 0<k<n
\end{cases}
\]

Trong đó:

- Nếu `k == 0` hoặc `k == n`, kết quả bằng `1`. Đây là các trường hợp cơ sở.
- Nếu `0 < k < n`, kết quả bằng tổng của hai tổ hợp nhỏ hơn.

### Chương trình {#chuong-trinh-to-hop}

```cpp
#include <iostream>
using namespace std;

long Tohop(int n, int k)
{
    if (k == 0 || k == n)
        return 1;
    else
        return Tohop(n - 1, k - 1) + Tohop(n - 1, k);
}

int main()
{
    int n, k;

    cout << "Nhap n va k: ";
    cin >> n >> k;

    if (n < 0 || k < 0 || k > n)
    {
        cout << "Vui long nhap n >= 0 va 0 <= k <= n." << endl;
        return 1;
    }

    cout << "To hop " << n << " chap " << k << " = ";
    cout << Tohop(n, k) << endl;

    return 0;
}
```

### Giải thích {#giai-thich-to-hop}

Hàm `Tohop(n, k)` tính tổ hợp bằng cách gọi lại chính nó:

- Khi `k == 0` hoặc `k == n`, hàm trả về `1`.
- Với các trường hợp còn lại, hàm tính tổng `Tohop(n - 1, k - 1)` và `Tohop(n - 1, k)`.

Ví dụ, tổ hợp chập 2 của 4 được tính như sau:

\[
C_4^2=C_3^1+C_3^2=3+3=6
\]

Khi nhập `n = 4` và `k = 2`, chương trình in kết quả `6`.

**Lưu ý:** Hàm trên phù hợp để minh họa đệ quy. Với giá trị `n` lớn, hàm có thể tính lặp lại nhiều tổ hợp và kiểu `long` có thể không đủ để lưu kết quả.

### Câu hỏi kiểm tra {#cau-hoi-to-hop}

Giá trị của tổ hợp chập 2 của 4 là bao nhiêu?

- A. 4
- B. 5
- C. 6
- D. 8

**Đáp án: C.** Theo công thức đệ quy, \(C_4^2=C_3^1+C_3^2=3+3=6\).

## Ví dụ 4: In các số lẻ nhỏ hơn hoặc bằng n theo thứ tự giảm dần {#in-le-giam-dan}

Có thể sử dụng đệ quy để in các số lẻ nhỏ hơn hoặc bằng `n` theo thứ tự từ lớn đến nhỏ.

### Chương trình {#chuong-trinh-in-le-giam-dan}

```cpp
#include <iostream>
using namespace std;

void InLe(int n)
{
    if (n < 1)
        return;

    if (n == 1)
        cout << n;
    else if (n % 2 != 0)
    {
        cout << n << '\t';
        InLe(n - 2);
    }
    else
        InLe(n - 1);
}

int main()
{
    int n;

    cout << "Nhap n = ";
    cin >> n;

    cout << "Cac so le la: ";
    InLe(n);
    cout << endl;

    return 0;
}
```

### Giải thích {#giai-thich-in-le-giam-dan}

Hàm `InLe(n)` thực hiện như sau:

- Nếu `n < 1`, hàm kết thúc.
- Nếu `n == 1`, hàm in số `1` rồi kết thúc.
- Nếu `n` là số lẻ lớn hơn `1`, hàm in `n` rồi gọi lại với `n - 2`.
- Nếu `n` là số chẵn, hàm gọi lại với `n - 1` để chuyển đến số lẻ nhỏ hơn.

Ví dụ, khi nhập `n = 8`, chương trình in:

```text
Cac so le la: 7    5    3    1
```

Các số được in theo thứ tự giảm dần vì mỗi lần gọi đệ quy, giá trị cần xét giảm dần cho đến `1`.

### Câu hỏi kiểm tra {#cau-hoi-in-le-giam-dan}

Khi gọi `InLe(8)`, dãy số lẻ được in ra theo thứ tự nào?

- A. `1 3 5 7`
- B. `7 5 3 1`
- C. `8 6 4 2`
- D. `7 5 3`

**Đáp án: B.** Hàm bỏ qua số chẵn và in các số lẻ từ `7` giảm dần đến `1`.

## In các số lẻ theo thứ tự tăng dần {#in-le-tang-dan}

Để in các số lẻ theo thứ tự tăng dần, có thể sử dụng thêm đối số `i`. Đối số này bắt đầu từ `1` và tăng thêm `2` sau mỗi lần gọi hàm.

### Hàm đệ quy {#ham-in-le-tang-dan}

```cpp
void InLeTangDan(int n, int i)
{
    if (i <= n)
    {
        cout << i << '\t';
        InLeTangDan(n, i + 2);
    }
}
```

Khi gọi hàm, truyền giá trị ban đầu của `i` là `1`:

```cpp
InLeTangDan(n, 1);
```

Hàm bắt đầu từ `1`, sau đó tăng `i` thêm `2` ở mỗi lần gọi. Khi `i > n`, điều kiện không còn đúng và hàm kết thúc.

Ví dụ, với `n = 8`, kết quả là:

```text
1    3    5    7
```

Khác với cách in giảm dần, cách này bắt đầu từ số lẻ nhỏ nhất và tiến dần đến các số lẻ không vượt quá `n`.

### Câu hỏi kiểm tra {#cau-hoi-in-le-tang-dan}

Trong hàm `InLeTangDan(n, i)`, câu lệnh nào giúp chuyển đến số lẻ tiếp theo?

- A. `InLeTangDan(n, i - 1);`
- B. `InLeTangDan(n, i + 1);`
- C. `InLeTangDan(n, i + 2);`
- D. `InLeTangDan(n - 1, i);`

**Đáp án: C.** Tăng `i` thêm `2` giúp lần lượt xét các số lẻ `1, 3, 5, 7, ...`.

## Câu hỏi ôn tập {#cau-hoi-on-tap}

**Câu 1.** Trong hàm `Tohop(n, k)`, điều kiện nào là trường hợp cơ sở?

- A. `n == 0` hoặc `k == 1`
- B. `k == 0` hoặc `k == n`
- C. `n < k`
- D. `k > n`

**Đáp án: B.** Khi `k == 0` hoặc `k == n`, tổ hợp bằng `1`, nên hàm không cần gọi đệ quy tiếp.

**Câu 2.** Muốn in các số lẻ từ nhỏ đến lớn bằng hàm có thêm đối số `i`, lời gọi ban đầu nào phù hợp?

- A. `InLeTangDan(n, n);`
- B. `InLeTangDan(n, 0);`
- C. `InLeTangDan(n, 1);`
- D. `InLeTangDan(1, n);`

**Đáp án: C.** Bắt đầu với `i = 1`, sau đó tăng `i` thêm `2` ở mỗi lần gọi để in các số lẻ theo thứ tự tăng dần.
