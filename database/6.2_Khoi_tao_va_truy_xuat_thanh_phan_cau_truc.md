## Mục tiêu bài học {#muc-tieu-bai-hoc}

Sau khi học xong bài này, người học có thể:

- Biết cách khởi tạo biến cấu trúc.
- Biết cách truy xuất và thay đổi thành phần cấu trúc bằng toán tử dấu chấm (`.`).
- Biết cách truy xuất thành phần thông qua con trỏ cấu trúc bằng toán tử mũi tên (`->`).
- Biết cách truy xuất thành phần của mảng cấu trúc và cấu trúc lồng nhau.

## Khởi tạo biến cấu trúc {#khoi-tao-bien-cau-truc}

Sau khi khai báo một kiểu cấu trúc, ta có thể tạo biến thuộc kiểu đó và khởi tạo giá trị cho các thành phần.

Ví dụ, khai báo cấu trúc sinh viên:

```cpp
struct Sinhvien
{
    char ms[9];
    char ht[40];
    int ns;
    int gt;
    float dtb;
};
```

Khởi tạo một biến sinh viên:

```cpp
Sinhvien sv = {"CNTT3801", "Le Trung Truc", 1995, 1, 5.5};
```

Các giá trị được đưa vào theo đúng thứ tự khai báo thành phần:

- `ms`: mã số sinh viên.
- `ht`: họ tên sinh viên.
- `ns`: năm sinh.
- `gt`: giới tính.
- `dtb`: điểm trung bình.

### Câu hỏi kiểm tra {#cau-hoi-khoi-tao}

Trong câu lệnh `Sinhvien sv = {"CNTT3801", "Le Trung Truc", 1995, 1, 5.5};`, giá trị `1995` được gán cho thành phần nào?

- A. `ms`
- B. `ht`
- C. `ns`
- D. `dtb`

**Đáp án: C.** Giá trị được gán theo thứ tự khai báo, nên `1995` thuộc thành phần `ns`, dùng để lưu năm sinh.

## Truy xuất thành phần bằng toán tử dấu chấm {#toan-tu-dau-cham}

Để truy xuất một thành phần của biến cấu trúc, ta sử dụng toán tử dấu chấm (`.`).

Cú pháp:

```cpp
ten_bien.ten_thanh_phan
```

Ví dụ:

```cpp
#include <iostream>
#include <cstring>
using namespace std;

struct Sinhvien
{
    char ms[9];
    char ht[40];
    int ns;
    int gt;
    float dtb;
};

int main()
{
    Sinhvien sv = {"CNTT3801", "Le Trung Truc", 1995, 1, 5.5};

    strcpy(sv.ht, "Nguyen Thanh Liem");
    sv.dtb = 5.5;

    cout << sv.ht << endl;
    cout << sv.dtb << endl;

    return 0;
}
```

Trong ví dụ trên:

- `sv.ht` dùng để truy xuất thành phần họ tên.
- `sv.dtb` dùng để truy xuất thành phần điểm trung bình.
- Phép gán cho phép thay đổi giá trị của thành phần tương ứng.

Khi sử dụng `strcpy()` để sao chép chuỗi ký tự, cần khai báo thư viện `<cstring>`. Chuỗi được sao chép phải vừa với vùng nhớ của mảng đích.

### Câu hỏi kiểm tra {#cau-hoi-toan-tu-dau-cham}

Toán tử nào được sử dụng để truy xuất thành phần của một biến cấu trúc?

- A. `->`
- B. `.`
- C. `::`
- D. `&`

**Đáp án: B.** Toán tử dấu chấm được dùng khi truy xuất thành phần trực tiếp từ một biến cấu trúc.

## Truy xuất thành phần thông qua con trỏ cấu trúc {#con-tro-cau-truc}

Khi sử dụng con trỏ trỏ đến một biến cấu trúc, ta có thể dùng toán tử mũi tên (`->`) để truy xuất các thành phần.

Ví dụ:

```cpp
#include <iostream>
#include <cstring>
using namespace std;

struct Sinhvien
{
    char ms[9];
    char ht[40];
    int ns;
    int gt;
    float dtb;
};

int main()
{
    Sinhvien y = {"CNTT3801", "Le Trung Truc", 1995, 1, 5.5};

    Sinhvien* p = new Sinhvien;

    strcpy(p->ht, y.ht);
    p->ns = y.ns - 1;
    p->dtb = y.dtb + 2;

    cout << p->ht << '\t' << p->ns << '\t' << p->dtb << endl;

    delete p;

    return 0;
}
```

Giải thích:

- `p` là con trỏ trỏ đến vùng nhớ dành cho một biến kiểu `Sinhvien`.
- `p->ht` truy xuất thành phần họ tên thông qua con trỏ.
- `p->ns` truy xuất thành phần năm sinh.
- `p->dtb` truy xuất thành phần điểm trung bình.
- `new` cấp phát vùng nhớ động; `delete p` giải phóng vùng nhớ đó sau khi sử dụng.

Toán tử `->` tương đương với cách viết `(*p).ht` khi truy xuất thành phần `ht`.

### Câu hỏi kiểm tra {#cau-hoi-con-tro-cau-truc}

Nếu `p` là con trỏ trỏ đến một biến kiểu `Sinhvien`, cách nào sau đây dùng để truy xuất thành phần `dtb`?

- A. `p.dtb`
- B. `p->dtb`
- C. `p::dtb`
- D. `p[dtb]`

**Đáp án: B.** Toán tử `->` được dùng để truy xuất thành phần cấu trúc thông qua con trỏ.

## Truy xuất thành phần của mảng cấu trúc {#mang-cau-truc}

Ta có thể khai báo mảng gồm nhiều phần tử thuộc cùng một kiểu cấu trúc.

Ví dụ:

```cpp
#include <iostream>
#include <cstring>
using namespace std;

struct Sinhvien
{
    char ms[9];
    char ht[40];
    int ns;
    int gt;
    float dtb;
};

int main()
{
    Sinhvien ds[80];

    strcpy(ds[1].ht, "Nguyen Quoc An");
    ds[1].ns = 1995;
    ds[1].dtb = 3.5;

    cout << ds[1].ht << '\t'
         << ds[1].ns << '\t'
         << ds[1].dtb << endl;

    return 0;
}
```

Giải thích:

- `ds` là mảng gồm 80 phần tử kiểu `Sinhvien`.
- `ds[1]` là phần tử thứ hai của mảng vì chỉ số mảng bắt đầu từ `0`.
- `ds[1].ht` truy xuất họ tên của phần tử thứ hai.
- `ds[1].ns` và `ds[1].dtb` lần lượt truy xuất năm sinh và điểm trung bình của phần tử đó.

Cú pháp tổng quát:

```cpp
ten_mang[chi_so].ten_thanh_phan
```

### Câu hỏi kiểm tra {#cau-hoi-mang-cau-truc}

Với khai báo `Sinhvien ds[80];`, biểu thức `ds[1].ht` truy xuất thành phần nào?

- A. Họ tên của phần tử đầu tiên.
- B. Họ tên của phần tử thứ hai.
- C. Năm sinh của phần tử thứ hai.
- D. Điểm trung bình của phần tử thứ hai.

**Đáp án: B.** Chỉ số mảng bắt đầu từ `0`, nên `ds[1]` là phần tử thứ hai và `.ht` là thành phần họ tên.

## Truy xuất thành phần trong cấu trúc lồng nhau {#cau-truc-long-nhau}

Cấu trúc có thể chứa một thành phần thuộc kiểu cấu trúc khác. Khi đó, để truy xuất thành phần bên trong, ta sử dụng nhiều toán tử dấu chấm liên tiếp.

Ví dụ:

```cpp
#include <iostream>
using namespace std;

struct Date
{
    int ngay;
    int thang;
    int nam;
};

struct Sinhvien
{
    char ms[9];
    char ht[40];
    Date ngaysinh;
    float dtb;
};

int main()
{
    Sinhvien sv3 = {
        "CNTT3803",
        "Phan Hanh Phuc",
        {27, 12, 1994},
        3.5
    };

    cout << sv3.ht << endl;

    cout << sv3.ngaysinh.ngay << '/'
         << sv3.ngaysinh.thang << '/'
         << sv3.ngaysinh.nam << endl;

    return 0;
}
```

Giải thích:

- `ngaysinh` là thành phần thuộc kiểu cấu trúc `Date`.
- `sv3.ngaysinh` truy xuất thành phần ngày sinh của sinh viên.
- `sv3.ngaysinh.ngay` truy xuất ngày sinh.
- `sv3.ngaysinh.thang` truy xuất tháng sinh.
- `sv3.ngaysinh.nam` truy xuất năm sinh.

Như vậy, cấu trúc lồng nhau giúp tổ chức các dữ liệu có liên quan thành từng nhóm rõ ràng.

### Câu hỏi kiểm tra {#cau-hoi-cau-truc-long-nhau}

Với cấu trúc `Sinhvien` có thành phần `ngaysinh` thuộc kiểu `Date`, biểu thức nào truy xuất năm sinh của sinh viên `sv3`?

- A. `sv3.nam`
- B. `sv3.Date.nam`
- C. `sv3.ngaysinh.nam`
- D. `sv3->ngaysinh`

**Đáp án: C.** Cần truy xuất thành phần `ngaysinh` trước, sau đó truy xuất thành phần `nam` bên trong cấu trúc `Date`.

## Câu hỏi ôn tập {#cau-hoi-on-tap}

**Câu 1.** Phát biểu nào đúng về toán tử `.` và toán tử `->` khi truy xuất thành phần cấu trúc?

- A. Cả hai chỉ dùng với biến cấu trúc thông thường.
- B. Toán tử `.` dùng với biến cấu trúc, còn `->` dùng với con trỏ cấu trúc.
- C. Toán tử `->` dùng với mảng số nguyên, còn `.` dùng với con trỏ.
- D. Hai toán tử luôn có thể thay thế cho nhau.

**Đáp án: B.** Dùng `.` khi truy xuất thành phần từ biến cấu trúc và dùng `->` khi truy xuất thành phần thông qua con trỏ cấu trúc.

**Câu 2.** Với cấu trúc `Sinhvien` có thành phần `ngaysinh` thuộc kiểu `Date`, biểu thức nào truy xuất tháng sinh của biến `sv3`?

- A. `sv3.thang`
- B. `sv3.ngaysinh.thang`
- C. `sv3.Date.thang`
- D. `sv3->thang`

**Đáp án: B.** Biểu thức `sv3.ngaysinh.thang` truy xuất thành phần `ngaysinh` trước rồi lấy thành phần `thang` bên trong.
