## Các kiểu dữ liệu cơ bản

Mỗi kiểu dữ liệu chuẩn trong C++ có 3 yếu tố đặc trưng: **Tên kiểu**, **Kích thước (số byte)** và **Miền giá trị**:

| Loại dữ liệu | Tên kiểu | Kích thước | Miền giá trị |
| :--- | :--- | :--- | :--- |
| Luận lý | `bool` | 1 byte | `false` (0), `true` (khác 0) |
| Ký tự có dấu | `[signed] char` | 1 byte | -128 .. 127 |
| Ký tự không dấu | `unsigned char` | 1 byte | 0 .. 255 |
| Số nguyên | `int` | 2 bytes (hoặc 4 bytes) | -32768 .. 32767 (hoặc -2147483648 .. 2147483647) |
| Số nguyên không dấu | `unsigned int` | 2 bytes | 0 .. 65535 |
| Số nguyên ngắn | `short [int]` | 2 bytes | -32768 .. 32767 |
| Số nguyên dài | `long [int]` | 4 bytes | -2147483648 .. 2147483647 |
| Số nguyên dài không dấu | `unsigned long` | 4 bytes | 0 .. 2^32 - 1 |
| Số thực đơn | `float` | 4 bytes | 3.4*10^-38 .. 3.4*10^+38 |
| Số thực chính xác kép | `double` | 8 bytes | 1.7*10^-308 .. 1.7*10^+308 |
| Số thực mở rộng | `long double` | 10 bytes | 3.4*10^-4932 .. 1.1*10^+4932 |

- **Kiểu luận lý (`bool`):** Kết quả của biểu thức so sánh/điều kiện luôn là kiểu luận lý (`0` tương ứng `false`, khác `0` tương ứng `true`).
- **Kiểu ký tự (`char`):** Biểu diễn ký tự theo bảng mã ASCII (ví dụ `'A'` có mã `65`, `'a'` có mã `97`, `'0'` có mã `48`, phím Enter xuống hàng có mã `13`). Gán `c = 'A'` tương đương `c = 65`. Để lấy giá trị mã ASCII của biến ký tự `c`, dùng `int(c)`.

```cpp
#include <iostream>
using namespace std;

int main() {
    char c = 'A';
    cout << "Ky tu: " << c << ", Ma ASCII: " << int(c) << endl;
    return 0;
}
```

### Câu hỏi

**Câu 1:** Kiểu dữ liệu `unsigned char` trong C++ có kích thước và miền giá trị là bao nhiêu?
- A. 1 byte, miền giá trị `-128 .. 127`
- B. 1 byte, miền giá trị `0 .. 255`
- C. 2 bytes, miền giá trị `0 .. 65535`
- D. 4 bytes, miền giá trị `-32768 .. 32767`

**Đáp án đúng:** B

**Giải thích:** Kiểu `unsigned char` (ký tự không dấu) chiếm 1 byte bộ nhớ và có miền giá trị từ `0` đến `255`.

**Câu 2:** Để in ra mã ASCII (giá trị số nguyên) của một biến ký tự `char c = 'A';`, ta sử dụng biểu thức nào trong lệnh `cout`?
- A. `char(c)`
- B. `int(c)`
- C. `float(c)`
- D. `bool(c)`

**Đáp án đúng:** B

**Giải thích:** Để sử dụng giá trị số (mã ASCII) của một biến ký tự `c`, ta chuyển `c` sang kiểu nguyên bằng `int(c)`.
