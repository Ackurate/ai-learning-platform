## 1. Mục tiêu bài học {#muc-tieu-bai-hoc}

Sau bài học, người học có thể:

- Hiểu nguyên tắc sao chép tập tin nhị phân.
- Sử dụng `get()` và `put()` để sao chép từng byte.
- Sử dụng `read()`, `write()` và `gcount()` để sao chép theo khối dữ liệu.
- Phân biệt hai phương pháp sao chép tập tin.

## 2. Nội dung lý thuyết {#noi-dung-ly-thuyet}

### 2.1. Yêu cầu bài toán {#yeu-cau-bai-toan}

Viết chương trình mô phỏng việc sao chép tập tin. Chương trình yêu cầu người dùng nhập tên tập tin nguồn và tập tin đích, sau đó sao chép dữ liệu từ tập tin nguồn sang tập tin đích ở chế độ nhị phân.

Khi sao chép, chương trình cần lưu ý:

- Tập tin nguồn phải mở được để đọc.
- Tên tập tin đích phải khác tên tập tin nguồn.
- Cần xác định cách xử lý khi tập tin đích đã tồn tại.
- Phải kiểm tra lỗi trong quá trình đọc và ghi dữ liệu.

**Câu hỏi trắc nghiệm**

Điều kiện nào cần được kiểm tra trước khi sao chép tập tin?

A. Tập tin nguồn phải mở được để đọc.

B. Tên hai tập tin phải giống nhau.

C. Tập tin nguồn phải là tập tin văn bản.

D. Tập tin đích phải chứa sẵn dữ liệu.

**Đáp án: A.** Chương trình cần mở được tập tin nguồn để đọc dữ liệu trước khi tiến hành sao chép.

### 2.2. Cách 1: Sao chép từng byte bằng `get()` và `put()` {#sao-chep-tung-byte}

Phương pháp này đọc từng byte từ tập tin nguồn rồi ghi byte đó vào tập tin đích. Đây là cách dễ hiểu, phù hợp để tìm hiểu thao tác đọc và ghi tập tin nhị phân.

**Ví dụ chương trình:**

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    char fnguon[100], fdich[100];
    char ch;

    cout << "Nhap ten file nguon: ";
    cin.getline(fnguon, 100);

    ifstream fi(fnguon, ios::in | ios::binary);

    if (!fi)
    {
        cout << "Khong mo duoc file nguon";
        return 1;
    }

    cout << "Nhap ten file dich: ";
    cin.getline(fdich, 100);

    if (string(fnguon) == string(fdich))
    {
        cout << "File dich phai khac file nguon";
        fi.close();
        return 1;
    }

    ifstream ft(fdich, ios::binary);

    if (ft.good())
    {
        cout << "File dich da ton tai";
        fi.close();
        ft.close();
        return 1;
    }

    ft.close();

    ofstream fo(fdich, ios::out | ios::binary);

    if (!fo)
    {
        cout << "Khong mo duoc file dich";
        fi.close();
        return 1;
    }

    while (fi.get(ch))
    {
        fo.put(ch);
    }

    bool loiDoc = fi.bad();
    bool loiGhi = !fo;

    fi.close();
    fo.close();

    if (loiDoc || loiGhi)
    {
        cout << "Sao chep file that bai";
        return 1;
    }

    cout << "Sao chep file thanh cong";

    return 0;
}
```

**Giải thích chương trình:**

- `ifstream fi(...)`: Mở tập tin nguồn để đọc.
- `ios::binary`: Mở tập tin ở chế độ nhị phân.
- `fi.get(ch)`: Đọc một byte từ tập tin nguồn vào biến `ch`.
- `fo.put(ch)`: Ghi byte trong `ch` vào tập tin đích.
- `while (fi.get(ch))`: Tiếp tục đọc và ghi cho đến khi không đọc được byte tiếp theo.
- `fi.bad()`: Kiểm tra lỗi đọc nghiêm trọng.
- `!fo`: Kiểm tra trạng thái ghi của tập tin đích.
- `close()`: Đóng tập tin sau khi xử lý.

Trong ví dụ này, chương trình từ chối sao chép nếu tập tin đích đã tồn tại. Việc kiểm tra này phù hợp với bài thực hành cơ bản, nhưng trong chương trình thực tế cần lưu ý rằng tập tin có thể được tạo bởi một tiến trình khác sau bước kiểm tra.

**Câu hỏi trắc nghiệm**

Trong vòng lặp `while (fi.get(ch))`, hàm `fi.get(ch)` có nhiệm vụ gì?

A. Ghi một byte vào tập tin đích.

B. Đọc một byte từ tập tin nguồn.

C. Xóa một byte trong tập tin nguồn.

D. Đóng tập tin nguồn.

**Đáp án: B.** Hàm `get()` đọc từng byte từ tập tin nguồn và lưu vào biến `ch`. Sau đó, `put()` ghi byte đó sang tập tin đích.

### 2.3. Cách 2: Sao chép theo khối bằng `read()`, `write()` và `gcount()` {#sao-chep-theo-khoi}

Thay vì đọc từng byte, chương trình có thể đọc nhiều byte vào một vùng đệm rồi ghi cả khối dữ liệu sang tập tin đích.

**Ví dụ chương trình:**

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    char fnguon[100], fdich[100];

    cout << "Nhap ten file nguon: ";
    cin.getline(fnguon, 100);

    ifstream fi(fnguon, ios::in | ios::binary);

    if (!fi)
    {
        cout << "Khong mo duoc file nguon";
        return 1;
    }

    cout << "Nhap ten file dich: ";
    cin.getline(fdich, 100);

    if (string(fnguon) == string(fdich))
    {
        cout << "File dich phai khac file nguon";
        fi.close();
        return 1;
    }

    ifstream ft(fdich, ios::binary);

    if (ft.good())
    {
        cout << "File dich da ton tai";
        fi.close();
        ft.close();
        return 1;
    }

    ft.close();

    ofstream fo(fdich, ios::out | ios::binary);

    if (!fo)
    {
        cout << "Khong mo duoc file dich";
        fi.close();
        return 1;
    }

    char buf[2000];
    streamsize n;

    while (fi.read(buf, sizeof(buf)) || fi.gcount() > 0)
    {
        n = fi.gcount();
        fo.write(buf, n);

        if (!fo)
        {
            cout << "Loi ghi file dich";
            fi.close();
            fo.close();
            return 1;
        }
    }

    bool loiDoc = fi.bad();

    fi.close();
    fo.close();

    if (loiDoc)
    {
        cout << "Loi doc file nguon";
        return 1;
    }

    cout << "Sao chep file thanh cong";

    return 0;
}
```

**Giải thích chương trình:**

- `char buf[2000]`: Tạo vùng đệm có sức chứa tối đa 2000 byte.
- `fi.read(buf, sizeof(buf))`: Đọc tối đa 2000 byte từ tập tin nguồn vào vùng đệm.
- `fi.gcount()`: Trả về số byte thực tế đã đọc trong lần đọc gần nhất.
- `fo.write(buf, n)`: Ghi đúng `n` byte từ vùng đệm sang tập tin đích.
- `while (fi.read(...) || fi.gcount() > 0)`: Cho phép xử lý cả khối dữ liệu cuối cùng nếu khối đó có ít hơn 2000 byte.
- `fi.bad()`: Kiểm tra lỗi đọc nghiêm trọng sau vòng lặp.

Ví dụ, nếu tập tin có 4500 byte, chương trình có thể đọc lần lượt 2000 byte, 2000 byte và 500 byte. Khối cuối cùng vẫn được ghi đầy đủ nhờ `gcount()`.

**Câu hỏi trắc nghiệm**

Nếu lần đọc cuối cùng chỉ nhận được 500 byte, `fi.gcount()` trả về giá trị nào?

A. 0.

B. 500.

C. 2000.

D. 4500.

**Đáp án: B.** `gcount()` trả về số byte thực tế đã đọc trong lần đọc gần nhất, không phải kích thước tối đa của vùng đệm.

### 2.4. So sánh hai cách sao chép {#so-sanh-hai-cach}

| Tiêu chí | Cách 1 | Cách 2 |
|---|---|---|
| Hàm sử dụng | `get()`, `put()` | `read()`, `write()`, `gcount()` |
| Cách xử lý | Từng byte | Theo khối dữ liệu |
| Vùng đệm | Không cần vùng đệm riêng | Sử dụng vùng đệm `buf` |
| Đặc điểm | Dễ hiểu, dễ theo dõi | Xử lý nhiều byte trong mỗi lần đọc và ghi |
| Phù hợp | Minh họa thao tác cơ bản | Sao chép tập tin có nhiều dữ liệu |

Cả hai phương pháp đều có thể sao chép dữ liệu nhị phân mà không cần diễn giải dữ liệu thành ký tự hay văn bản. Phương pháp theo khối thường giảm số lần gọi thao tác đọc và ghi, nên phù hợp hơn với tập tin lớn.

**Câu hỏi trắc nghiệm**

Điểm khác biệt chính giữa hai phương pháp sao chép là gì?

A. Cách 1 chỉ đọc tập tin văn bản.

B. Cách 2 không cần mở tập tin nguồn.

C. Cách 1 xử lý từng byte, còn cách 2 xử lý theo khối dữ liệu.

D. Cách 2 không cần ghi dữ liệu sang tập tin đích.

**Đáp án: C.** Cách 1 sử dụng `get()` và `put()` cho từng byte; cách 2 sử dụng vùng đệm cùng `read()` và `write()` để xử lý theo khối.

## 3. Kết luận {#ket-luan}

Sao chép tập tin nhị phân là quá trình đọc dữ liệu từ tập tin nguồn và ghi dữ liệu sang tập tin đích mà không làm thay đổi nội dung byte.

Có thể sử dụng `get()` và `put()` để sao chép từng byte, hoặc sử dụng `read()`, `write()` và `gcount()` để sao chép theo từng khối dữ liệu. Trong cả hai trường hợp, cần kiểm tra việc mở tập tin, trạng thái đọc và ghi để phát hiện lỗi.

## 4. Câu hỏi ôn tập {#cau-hoi-on-tap}

**Câu 1.** Trình bày cách sao chép tập tin nhị phân bằng `get()` và `put()`. Vai trò của từng hàm trong quá trình sao chép là gì?

A. `get()` ghi dữ liệu, `put()` đọc dữ liệu.

B. `get()` đọc từng byte, `put()` ghi byte đó sang tập tin đích.

C. Cả hai hàm chỉ dùng để mở tập tin.

D. Cả hai hàm đều dùng để đóng tập tin.

**Đáp án: B.** `get()` đọc một byte từ tập tin nguồn, còn `put()` ghi byte đó vào tập tin đích.

**Câu 2.** Công dụng của `read()`, `write()` và `gcount()` là gì?

A. `read()` đọc theo khối, `write()` ghi dữ liệu, `gcount()` cho biết số byte thực tế đã đọc.

B. `read()` xóa dữ liệu, `write()` mở tập tin, `gcount()` đóng tập tin.

C. Cả ba hàm đều chỉ dùng để đọc từng ký tự.

D. `gcount()` cho biết tổng dung lượng ổ đĩa.

**Đáp án: A.** Ba hàm phối hợp để đọc dữ liệu theo khối, ghi đúng số byte đã đọc và xử lý chính xác khối dữ liệu cuối cùng.
